# E1＋Feature 准备范围

直接复用已固定的 p2_feature_v1 联合训练实现，独立 E1 启动管理器；不复制或改动训练核心。E0/E1 使用同一配置、数据、缓存、预算和初始化，训练器原生 pair.json 强制配对一致，输出分别为同一 production 下的 E0/E1。新管理目录单独保存节点状态和日志，使用独立端口。

生成目标为 AV + 0.1 video Feature + 0.1 audio Feature + 0.05 Event；Event 系数沿用既有 E1 配置。只准备与 CPU 验证，不启动 GPU、不设置自动接续。新训练从共享预训练初始化开始，只允许从本 E1 目录恢复。

现有 joint_event 模式已满足损失与梯度需求，另建训练核心会增加配对变量；只给裸 CLI 命令则缺少三机管理、恢复防串和结果指路，因此补齐专用入口并验证梯度、恢复、监控及配对。
