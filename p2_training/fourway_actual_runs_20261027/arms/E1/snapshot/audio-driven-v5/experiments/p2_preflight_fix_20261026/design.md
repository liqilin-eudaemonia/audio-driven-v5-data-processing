# 训练预检查去重修复与实际 GPU 验证

用户已授权停止 E0、使用三机测试，验证修复后重新启动同数据同 seed 的 E0。E0 停止前尚未创建 run.json、没有优化器更新；E1 已完成并保留。

采用一次完整审计＋持久校验凭证＋每次共享轻量复核，保留训练逐样本 payload SHA256。避免只删除检查（会失去完整性和类别统计），也避免每个 rank 独立分片后每次重算全部缓存（无法复用 E0/E1/恢复的结果）。

实现放在独立 `releases/p2_preflight_v1`：Python 包搜索路径覆盖 training.py、config.py，其他 P2 模块从当前原版读取。原版 features.py / contracts.py 路径不变，已有缓存身份可直接复用；新 source_identity 精确记录实际覆盖文件，不伪造旧源码身份。原生 CLI 通过该 release 启动器加载。原代码与原 E1 检查点生成/恢复入口保持可用。

审计 key 绑定配置（去除纯输出位置）、源码、模型资产、输入/目标清单哈希及缓存视图位置。首次由一个进程按原逻辑完整验证媒体、input/VAE/events（启用 feature 时包括 teacher），保存原类别统计、标签签名与准入所需 provenance 字段。保存每个依赖的解析路径、size、mtime_ns、ctime_ns；完整审计前记录依赖快照，审计完成再复核快照，拒绝审计期间的变化。凭证内容有 SHA256 完整标记，文件锁保证单写者，失败不发布成功凭证。

后续启动由 rank0 复核凭证与依赖元数据；变更自动重审，损坏直接报错。完整 payload 在训练读取时仍逐次 SHA 校验。轻量 stat 不是对恶意保持所有元数据的修改的密码学证明；凭证用于受控共享数据目录、逐次数据读取哈希仍是最终保障。

分布式在 CUDA/NCCL 初始化前使用共享目录会合。每次启动显式传入所有 rank 相同的随机 `P2_PREFLIGHT_SESSION`，request/result/ack 原子写出且拒绝重复 session。各 rank 比较配置、源码、资产和清单 binding；只有 rank0 审计或复用并发布结果，其他 rank 读取统计。错误广播与超时防止永远等待。全量依赖 stat 也只由 rank0 做。假定当前数据/缓存/会合目录为三机共享存储。

E0 重启到独立结果目录，配置训练参数及输入完全复用，仅 output 不同。与原 E1 的跨版本校验只允许实际源码/输出位置不同；初始化、数据/标签/统计、seed、预算、world、资产、LoRA 和数值设置必须完全相同。差异明确记录为预检查 I/O 优化，不改既有 pair.json 或 checkpoint 身份。

验证：CPU 覆盖 full/reuse 统计一致、并发仅一次全审、数据/标签/marker/payload 改动失效、同 size+mtime 篡改由 ctime/运行时 SHA 拦截、缺失/损坏/中途变化、错误传播、session 过期复用。实际 H200 对照原版和新版相同 seed 的 E0/E1 更新；三机 6 GPU 数值对照、恢复与三机 24 rank 预检查验证。比较模型、优化器、RNG、样本序列和类统计。通过后重新启动正式三机 24 卡 E0；E1 原版源码保持不变。
