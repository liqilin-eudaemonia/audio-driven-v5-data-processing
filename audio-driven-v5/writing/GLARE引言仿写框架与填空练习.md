# GLARE 引言仿写框架与填空练习

更新日期：2026-11-06。返回 [论文写作总索引](README.md)。参考 [GLARE 原文](00_GLARE_local.pdf) 第 1—2 页 Introduction。

**练习进度：** 作者已完成 P1—P3 和 P4 数据部分的逐段讨论，合并正文见 [中文引言初稿](中文论文初稿_引言与任务数据.md)。本文件保留原始空白框架，方法、benchmark 方案和贡献列表仍待补写。

本练习保留段落任务、句子功能与衔接方式，具体内容留空，由作者填写。学习 GLARE 的论证结构，不复制它的句子、方法或首次主张。**先写中文；方法尚未确定，方法和实验结果位置继续留空；具体评价指标以后再定。**

**一 GLARE 的引言怎样推进**

GLARE 的引言由四个主要正文段落和一组贡献列表组成。下表概括原文的写作功能，不是原文翻译。

| 单元 | 原文位置 | 这一段完成什么任务 | 为什么下一段有必要 |
|---|---|---|---|
| 第 1 段 | PDF 第 1 页，行 22—28 | 从说话者生成的进展引出倾听者的重要性，再说明反应与自然度的关系 | 读者需要知道已有研究发展到哪里、还缺什么 |
| 第 2 段 | PDF 第 1 页，行 29—38 | 承认倾听生成已有进展，提出两个瓶颈，并展开数据和反应标注的不足 | 仅有训练数据还不能回答如何判断输出是否合适 |
| 第 3 段 | PDF 第 2 页，行 39—45 | 展开评价不足，说明视觉质量与反应适当性的区别，并承认反馈可以有多种合理实现 | 问题已经明确，需要一个相应的解决方案 |
| 第 4 段 | PDF 第 2 页，行 46—54 | 按数据、模型、评价的顺序概述工作，每部分回应前文需求 | 需要用简洁条目压缩本文贡献 |
| 贡献列表 | PDF 第 2 页，行 55—63 | 分别列出数据、方法、评价贡献 | 引言结束，后续章节逐项展开与验证 |

整体逻辑是：

> 需要什么能力 → 已有研究提供了什么 → 数据还缺什么支持 → 评价还缺什么支持 → 本文如何回应 → 三项贡献。

GLARE 特别强调反应类别与时间监督；本文具体采用什么反应定义、模型和评价仍按自己的研究决定。原文将其方法称作 baseline，也不要求本文采用相同定位：本项目的模型 pipeline 是核心贡献方向之一。

**二 我们借用的引言骨架**

| 段落 | 本文中的功能 | 当前是否填写 |
|---|---|---|
| P1 | 从真实交流需求引出倾听阶段的视听反馈，限定本文研究目标 | 现在先填这一段 |
| P2 | 简述已有工作，说明本任务需要哪些数据支持 | P1 修改后再填 |
| P3 | 说明为什么需要专门的测试与比较协议 | 先留位置；暂不确定具体指标 |
| P4 | 概述数据、模型 pipeline、benchmark 如何共同回应问题 | 可以先填已确定的数据内容，方法与结果留空 |
| C | 三项贡献列表 | 正文和方法稳定后再填写 |

下面的“填写提示”属于框架，空白处才是你的内容。第一遍不要求像论文，也不要求引文齐全；先把意思说清楚。未经核实的事实可写“待查”，不必为了连成句子填入猜测。

**P1 先让读者理解任务价值**

本段只回答：什么场景需要什么能力，为什么它值得研究？先不介绍模块、数据规模或结果。

| 句子 | 这句话的任务 | 你的内容 |
|---|---|---|
| P1-1 | 从一个真实交流场景或已经确认的研究背景开始 | __________ |
| P1-2 | 说明倾听者在这个场景中通过哪些行为参与，以及这些行为起什么作用 | __________ |
| P1-3 | 说明这给数字人提出了什么能力需求 | __________ |
| P1-4 | 用一句话收束到本文的研究对象；必要时简要限定输入与输出 | __________ |

可选句式骨架，具体内容自行填写：

> 在【__________】中，【__________】。倾听者通过【__________】，表达【__________】。因此，面向【__________】的数字人需要【__________】。本文聚焦【__________】。

你的第一段：

> 【待填写】

段末衔接：这一能力值得研究，接下来读者会问“已有工作是否已经支持它？”

自查：这一段是否能让不了解你模型的读者理解任务？是否在不需要介绍模型名的情况下说清价值？

**P2 从已有进展引出数据需求**

本段承接 P1：先承认已有支持，再说明具体距离。不要把某个数据集的问题推广到所有资源。

| 句子 | 这句话的任务 | 你的内容 |
|---|---|---|
| P2-1 | 简述与 P1 目标相关的已有研究进展 | __________ |
| P2-2 | 限定本文具体关注的任务条件，与已有设定建立区别 | __________ |
| P2-3 | 指出某类现有资源尚缺什么任务支持，并标出依据 | __________ |
| P2-4 | 解释这种不足会怎样影响学习或研究 | __________ |
| P2-5 | 得出“因此需要什么数据工作”，为后文贡献埋下伏笔 | __________ |

可选句式骨架：

> 已有研究在【__________】方面取得进展【引用待补：__________】。对于本文关注的【__________】，现有【资源范围：__________】仍需要【__________】。具体而言，【已核实的问题：__________】，使得【对任务的影响：__________】。因此，需要【__________】。

你的第二段：

> 【待填写】

证据备忘：资源或论文 __________；对应事实 __________；待核项 __________。

段末衔接：有了适合学习的数据，还要能比较生成结果是否完成了任务。

自查：是否说清了“不足 → 影响 → 需要补充的工作”？是否用准确的资源范围取代了“所有工作都没有”？

**P3 为 benchmark 建立必要性**

本段只回答“已有评价回答了什么、本文还需要回答什么”。不选择指标、不设计公式，也不用现在完成本段。

| 句子 | 这句话的任务 | 你的内容 |
|---|---|---|
| P3-1 | 承接数据需求，引出评价需求 | __________ |
| P3-2 | 概括已有评价或测试集能够覆盖的内容 | __________ |
| P3-3 | 指出它对本文目标仍有哪些未充分覆盖的问题 | __________ |
| P3-4 | 得出需要怎样的专门测试与比较协议，仅写目标 | __________ |

可选句式骨架：

> 除【前文需求：__________】之外，研究这一任务还需要【__________】。现有【评价范围：__________】能够反映【__________】，但对【具体问题：__________】的支持仍需完善。因此，本文还需要【协议目标：__________】。

你的第三段：

> 【待填写】

段末衔接：前文已明确研究需求，下一段应逐项说明本文如何回应。

自查：有没有在定义研究目标之前陷入指标细节？有没有把尚未决定的评测方式写成既成方案？

**P4 让数据 模型与 benchmark 回应前文问题**

本段介绍整体工作。各部分只写一至两句，解释其作用即可。方法尚未确定时，保留空位，不从旧版本中挑一个强行填入。

| 句子 | 这句话的任务 | 你的内容 |
|---|---|---|
| P4-1 | 用一个总判断承接前文需求，概述本文路线 | __________ |
| P4-2 | 数据工作做了什么，对应 P2 的哪个需求 | __________ |
| P4-3 | 已有框架直接用于本任务还有什么困难，模型 pipeline 如何处理它 | __________（先完成大致内容，方法确定后再细化） |
| P4-4 | Benchmark 提供什么比较支持，对应 P3 的哪个需求 | __________ |
| P4-5 | 可选：概括一个已经验证的主要发现 | __________（结果确定后再填） |

可选句式骨架：

> 为回应上述问题，我们从【__________】展开研究。首先，我们【数据工作：__________】，以支持【__________】。在此基础上，我们提出【方法：__________】，用于【__________】。进一步，我们建立【benchmark：__________】，支持【__________】。

你的第四段：

> 【待填写】

段末衔接：读者已理解工作全貌，最后用贡献列表留下三个明确记忆点。

自查：P4 是否真正回应 P2、P3？模型是否有明确研究作用？是否提前声称了未经实验验证的效果？

**C 贡献列表最后填写**

贡献是前文论证的压缩。每项写“做了什么＋具体新增支持”，不要在列表里突然引入正文没有解释的新问题。

- 数据贡献：__________。
- 模型 pipeline 贡献：__________。
- Benchmark 贡献：__________。

| __________ | __________ | __________ |
| __________ | __________ | __________ |

**三 一次只写一段**

1. **本次先写 P1。** 先填 P1-1 至 P1-4，再连成三至四句。可以用口语，不必写英文或找漂亮句式。
2. **检查 P1 的逻辑。** 我会区分你的核心意思、需要衔接的地方和需要证据的地方，再给出尽量保留你表达的修改稿。
3. **P1 稳定后写 P2。** 用同样方式处理已有工作、数据不足及其影响。
4. **P3 保留目标层面的内容。** 不推进具体指标，必要时继续空着。
5. **P4 的方法和结果、贡献列表最后填。** 在方案未定时，不要求整篇引言一次写完。
