# 事件级评测框架：当前确认版

框架确认日期：2026-11-06；七类事件与统计口径确认日期：2026-11-08。返回 [写作总索引](README.md)。

作者已确认以下三组评价，并于2026-11-08确认四类视觉、三类音频事件，以及参考正例支持的宏平均口径。完整检测／评分／报告及小规模真实执行已完成，入口见[评测模块](../evaluation/event_presence/README.md)与[实际验收](../experiments/p2_event_presence_pilot_20261108/README.md)；独立人工核验、阈值校准、人工评分量表和正式测试规模仍待落实。已有OmniResponse扩展指标与新整段语义指标分开记录，不能混淆实现与正式执行状态。

## 1. 任务与方法背景

输入为当前 speaker audio 与 listener 首帧，生成倾听期间的 listener 音视频。当前指定版本采用 Feature 对 Qwen 衍生的 Connector 条件映射提供监督、Event 对 LTX 最后 block 的 hidden 提供整段监督、speaker Whisper cross-attention 指导生成。Qwen 基座冻结且未接规划 SFT LoRA；训练使用真实描述构造guided条件，推理以模型预测描述替代。完整关系见[中文初稿第五部分](中文论文初稿_引言与任务数据.md)。

[当前 LTX Event 实现](../related/P2_LTX主干整段与时序事件监督_20261106.md)在有效视频和音频位置分别聚合后进行多标签预测，当前 temporal weight 为零。评测粒度的理由是倾听回应具有多种合理实现，而不仅是训练采用整段损失：允许事件时间变化，甚至存在合理的类别替代，不把唯一真实时间轴视为唯一正确答案。

## 2. 已确认的三组评价

| 评价组 | 主要内容 | 结论边界 |
|---|---|---|
| 整段事件类别一致性 | 视觉、音频分别报告 Precision、Recall、Macro-F1及逐类结果 | 衡量与参考中观察到的类别一致性，不等于语境正确率 |
| 语境适当性与参与感 | 结合当前 speaker audio 和生成 listener 音视频，评价反馈是否适当、自然、不过度，并体现参与 | 允许与单一 GT 不同但合理的回应；初版以人工评价为基础 |
| 视听事件协调性 | 评价生成声音与生成动作是否构成协调反馈 | 比较生成结果内部的视听关系，不要求复现 GT 时间 |

### 整段事件类别一致性

**为何采用整段类别而非固定时刻匹配。** 当前话语通常约束反馈的情感与态度方向，例如微笑或共同发笑可以回应开心的分享，摇头可以表达不同意见。但这些关联不是确定规则：反馈方向相近时，具体行为、发生时刻、持续时间和次数仍可不同；微笑也可能替代笑声。同一句话可以对应多种合理的反馈时间安排，不能把观察到的一条时间轴当作唯一正确答案。因此，主事件指标先比较整段是否包含相应类别，避免将合理的时间变化直接判错；类别替代是否合理、反馈是否过早或过长，则结合语境与自然度评价。

从最终生成音视频提取事件，同一类别多次出现只记一次，不因重复增加得分，也不要求与 GT 有时间重叠。对每类在测试集上累计 TP、FP、FN，计算 `F1_c = 2TP_c / (2TP_c + FP_c + FN_c)`，再对类别取平均。视觉与音频分别报告，避免高频视觉类别掩盖声音反馈不足。

例：参考为“点头、微笑、短促附和”，生成为“点头、微笑、笑声”。点头和微笑匹配，短促附和遗漏，笑声为相对参考的额外类别；额外笑声是否不适当由第二组评价判断。点头时间不同不影响本项，点头五次不会比一次得分更多。

该指标是片段级多标签评价，不称为事件实例定位准确率。2026-11-08确认的细则：双空不产生TP、不填满分；主宏平均仅纳入冻结参考中有正例的类别，无正例类单列误报；unknown／error不作负例；多次生成逐draw评分后等权汇总，不按GT择优。多方法按逐类共同有效ID比较，完整覆盖不足时另报子集和缺项，不能利用大量无事件样本虚增成绩。F1公式本身不作为新指标发明，贡献围绕任务化的视听评价协议展开。

### 语境适当性与参与感

评审获得模型可用的当前 speaker audio 和生成结果，判断反馈是否符合话语、是否过度或明显冲突，以及倾听表现是否自然。可采用适当性评分或成对偏好率，具体形式待定。反馈数量不是质量的替代指标，安静倾听也可能合理。自动多模态评审仅作为候选辅助方案，须与人工判断核验后使用。

### 视听事件协调性

检查可听笑声与笑态／面部动态、短词发声与口部动作等是否协调。初版可用人工评分，自动事件对应方法待类别与检测可靠性明确后再定。无发声输出不因“无冲突”而获得满分，应单列发声比例、适用样本数；不要求点头必有声音或微笑必有笑声。联合生成优于级联生成需要实验支持，不由架构直接断言。

## 3. 与 GLARE 的关系

[GLARE 第6—7页及附录D](00_GLARE_local.pdf)的 R-F1 要求类别相同且时间 IoU≥0.5；R-tIoU、R-ATD衡量参考时间对齐，R-FID考察反应区间视觉质量。本文借鉴行为评价思路，将主自动指标改为整段类别一致性，不以 R-tIoU 或 R-ATD作为主指标。反应片段画质可作为后续补充，不替代音频、语境或视听协调评价。

不对齐 GT 时间不意味着忽略所有时间问题：生成音画之间的协调、反馈持续过久等仍会影响自然度。GLARE本身也承认单参考比较不是对合理性的绝对判断。

## 4. 类别与执行原则

**2026-11-08已确认七类。** 视觉为点头、摇头、微笑／笑态、皱眉；音频为可听笑声、简短词语回应、非词汇回应（排除笑声）。抬眉、眨眼、视线变化等暂作辅助。yeah／okay／right／no／wow等独立短词归词语回应；mhm／uh-huh／hmm／uh／ah／oh归非词汇回应；持续长句另标，难判为unknown。完整操作定义见[评测模块](../evaluation/event_presence/README.md)。不能直接把训练19类或训练正例门槛当作评测标准。

- 允许多标签同时出现；视觉笑容与可听笑声分开，不从一个推断另一个。
- 抬眉不自动等于惊讶，speech不自动等于backchannel，物理动作与心理情绪分别定义。
- 评价完整采样后的音视频，使用冻结的外部评价流程；训练Event head的准确率不能替代生成效果。
- 在人工核验子集上验证检测可靠性，避免训练标签与自动评审共享误差造成虚高分数。
- 未提及、未知和明确不存在分开；[训练弱负例与冲突屏蔽](../related/P2_整段Event数值缓存_20261106.md)不能直接升级为完整测试真值。
- 测试集及阈值校准集须与实际训练范围隔离。当前500h含部分源dev，不能将全部原dev作为未见验证集。

逐帧Emo-Acc、像素相似性及时间匹配指标都依赖单参考。保留它们用于诊断和可比性，不改变主事件评价允许时间变化的立场。音频“误发声”也仅指相对参考的额外活动，是否真的不合适需要语境判断；安静输出则需结合应答遗漏及适用覆盖一起解释。
