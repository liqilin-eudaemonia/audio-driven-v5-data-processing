条目减少和字符减少只针对通过子集，不能与全100条输入的995条视觉事件直接比较，也不能当作准确率提升。

最终拒绝原因：21条证据与所选区间不重叠、9条指向另一条support而非保留条目、1条原文引用错误、1条输出截断、1条通过宽记录连接分开发生的动作、1条语义自检拒绝。全部保留原始响应，没有放宽时间／来源检查来凑通过率。

**结论：当前8B基线不能直接用于全量自动发布。** 它在长事件列表上仍会把同类但不同时间的动作当成重复；通过样本也可能有附带描述重复和冲突披露不足。模型自检不是独立真值审核。问题样本在批量运行中同样得到上述4条候选，质量限制相同。

运行保存每次模型原始提案与自检、失败原因、代码快照和协议哈希。失败样本没有候选prompt，不会偷偷使用原始重复内容兜底。CPU验收会重新编译提案并逐字段比较结果，检查音频文字、次数及有效区间全部保留；它不判断实际画面中的动作真值。
