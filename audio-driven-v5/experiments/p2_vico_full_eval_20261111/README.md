## 执行与依赖

EMOCA沿用原官方编码和裁脸路径，FP32、batch16，按人物分片。仅在本任务进程中禁用不使用的wandb日志模块，避免共享环境wandb/protobuf冲突；不修改共享包。图像指标使用原vico_eval环境和官方脚本，FID/CSIM batch64。各worker保留断点回执；监督器只重试本次失败任务，未停止其他任务。
