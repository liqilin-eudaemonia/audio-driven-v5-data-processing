node12 的八个既有 rg 进程在 12.58 秒采样窗口中共用约 56.06 核；本次没有终止它们。node17 第二轮存在短时内存压力（memory PSI avg10 约 3.09%），尽管 MemAvailable 仍高，不能只凭空闲内存承诺没有竞争。

评估：可以让 J 以 CPU 低并发分片运行；每台先 1 个源视频 worker、Torch 2 线程、OpenBLAS 1 线程，GPU 保留给训练，暂不生成 4K 审核预览。优先复用已有转写/VAD/RMS、归一化音频与精确区间 QC 缓存，输出时间及状态。

先在 node8/node4 进行 5～10 分钟共存试验，观察训练滚动中位数/P95；稳定后再加入 node17/node12。建议持续慢于邻近基线 5% 时退让，不把正常验证/存盘耗时算入同一比较。该阈值是建议，不是已经实测无影响。

四机共享 /private 与 /public 的 WekaFS；当前低 iowait/PSI 不代表存储和网络无限空闲，eth0 数据也不代表完整 RDMA/Weka 流量。任一 rank 的数据读取变慢可能拖慢同步训练。没有做带宽压力测试。

当前固定 J 仍是样本 runner；正式多机需独立分片、去重、断点续跑和资源上限，不能直接运行仍导入旧 V1 的旧全量入口。

证据：summary.json、各节点 node*.json 与 node*.sample2.json、training_baseline.json。
