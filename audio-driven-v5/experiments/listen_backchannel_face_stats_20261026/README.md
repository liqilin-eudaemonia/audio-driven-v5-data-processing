## 事件数的实际限制

微笑类候选占总候选数约 68.94%。现有整合结果仍可能把持续微笑保留为多个短区间描述，因此“候选条数更多”不能直接解释为“真实动作发生次数更多”。

实查最高密度片段 `improvised_V00_S0849_I00000908_local_fbc7f7554a94`：4.022 秒、93 条候选，其中 92 条 smile，区间并集覆盖约 99.45%；前几条包含同一时间段的不同微笑描述。这些是现有结果，不是统计脚本新拆出的条目。

另有 84,888 段的全部已归类候选仅为 smile。建议结合七类计数、`non_smile_event_count` 和覆盖时长判断，不直接把按总数/密度取前 N 当作最终训练集。统计保留原结果；如果希望按真实次数筛选，需要另行决定持续状态与重复描述的事件单位。

## 验证

- 6 项测试通过，覆盖重叠区间、多类别计数、原文不变、缺失人脸、源身份、哈希、构建/筛选/回查/恢复和失败不能完成。
- 1,024 个整合分片全部核对 SHA256、条数和事件数；722,706 条源行逐条核对 SHA256、源时间和 listener 媒体身份；全量样本主键唯一；SQLite 完整性通过。
- 本次 CPU 统计、汇总与输出审计共 199.2 秒，使用 16 个读取进程。
- [validation_selection50](validation_selection50/selection.json) 仅用于验证筛选导出：p10≥128、有效比例≥0.9、候选≥3、排除已记录问题、按密度取前 50。它刻意检验排序极端结果，不是推荐训练集，勿作为自动训练配置。
- 原始描述、整合标签、媒体、缓存、split 与训练准入状态均未改动。
