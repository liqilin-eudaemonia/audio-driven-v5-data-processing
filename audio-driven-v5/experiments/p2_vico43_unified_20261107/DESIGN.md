# ViCo43 可复核的本地统一比较

用户已选择：按推荐方案直接实施，适配和评分细节由执行者依据审计确定。

目标是在已有进度上增加可信、可运行的视觉基线，提供完整逐条视频、统一分数及不确定性；不将暂停的诊断模型登记成正式基线。

选择共同输入的本地实验，而非在缺失协议下声称复现 DIM 原表。主表复用冻结的联合8000、DyStream listener 适配，并优先加入官方 Avatar Forcing 的无 user 视觉适配。正式 test43 全部保留、每个 UUID 独立输出，包括共享 speaker 音频的不同 listener。不得按 GT 选 seed、候选或最佳人物模型。

输入为相同 speaker 波形、相同 listener 首帧及片段时长；Avatar Forcing 自身音轨为全零、user 视觉在模型条件空间置零。保持官方网络、核心权重、CFG 2/1、nfe10、KV cache；统一 seed137、一次采样。直接使用已裁好首帧，不二次裁脸。官方 CLI 的30秒预处理上限不用于截断共同测试时长，改为对完整波形调用同一模型，并记录长片段验收。

原生512/25视频保留。评分按现有协议：原始RGB抗混叠缩小256，最近时间戳映射到GT30fps，尾端夹取并披露误差，无时间拉伸。使用同一官方 PSNR/SSIM/FID/CSIM/CPBD，及相同 BFM/DECA 提取与动作定义；原有缓存仅在哈希一致时复用。BFM、DECA、EMOCA分别标明，不能跨空间排名。

对逐条可聚合指标补充配对差值及按来源对话聚类bootstrap区间；集合FID不冒充逐片段指标。43条/40个speaker时段的重复关系需显式记录。报告检测缺失、短片段指标覆盖、失败和每条时间映射。

补充表保留 L2L 四套官方人物权重的 ViCo 迁移动作，明确额外 speaker motion、无写实renderer、未在ViCo重训。DIM等已发表数字独立引用，不能与本地分数拼接或算提升。

输出包含冻结协议、来源和权重指纹、输入验收、生成/评分、逐条CSV、结果说明、完整视频对比页面和实际检查记录。禁止将环境安装或部分生成标为全部完成；新增模型资源/执行失败必须明确记录，继续完成可运行模型的统一结果。

资源使用：先检查真实GPU进程，保留已有训练/推理；独立环境安装，不修改旧环境与封存代码。单worker起步，显存不足即退出，不清理其他进程。L2L训练保持停止。
