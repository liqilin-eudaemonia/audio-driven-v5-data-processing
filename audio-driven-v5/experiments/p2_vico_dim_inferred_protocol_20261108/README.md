## 推断规则

1. 先依据论文明确陈述、固定版本公开代码和EMOCA官方默认实现作选择；代码出现与数学定义明显矛盾的行为时注明修正理由。
2. 论文、代码有冲突时保留两种有依据的解释作敏感性分析，不通过遍历设置或调整尺度匹配原表数字。
3. GT统计用于诊断，不能仅因某个设置更接近论文的舍入数就认定作者用了它；不查看生成成绩来选择协议。
4. 明确列出仍不能推断消除的差异，尤其单次／多次采样、原生系数／RGB反提取。现有已封存成绩不改名成不存在的新实验。

## 已完成的GT诊断

仅使用冻结GT动作特征，未用生成分数选设置。固定比较三种已知样本范围、四种有明确含义的Var统计及两种SID聚合；未扫描裁脸、权重或缩放系数。

完整43条GT、16,288帧：

| 方差定义 | Exp | Pose |
|---|---:|---:|
| 发布代码：全部帧和系数拉平 | 1.45625 | 0.02328 |
| 各系数分别跨帧算方差，再平均 | 0.90443 | 0.01205 |
| 每条先拉平算方差，再等权平均 | 1.50995 | 0.02627 |
| 每条先算各系数时序方差，再等权平均 | 0.26175 | 0.00510 |
| DIM发表GT | 0.93 | 0.01 |

这说明**Var定义本身是一个合理的差异来源**，不能将GT不一致直接归因于EMOCA权重或裁脸错误。0.90443更接近0.93并不能证明作者采用第二种定义，因此主结果没有替换公式。

在同一实际有效帧、同一组GT拟合聚类上：全局SID为exp5.04158／pose3.88317；逐片段熵等权平均为1.09696／0.93648。论文GT为5.03／4.07，结合发布代码，这支持以全局汇总作为当前复现设置；仍未精确复现pose统计。
