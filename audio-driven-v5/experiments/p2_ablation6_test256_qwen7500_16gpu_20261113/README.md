## 运行与恢复

仅 node12、node11 各GPU0–7，共16卡，node8不参与。6×256共1536条，复用同身份64条×6＝384条输出，新增1152条；Qwen7500的256条条件全部复用。与已完成完整模型256条的样本、GT、seed137、Euler30、CFG3/7一致，原生消融模型及组件开关不变。

入口 `run.py activate` 首次核查资源并启动；恢复用 `run.py queue`。使用 `/private/liqi_workspace/project_code/Omni-LTX-stage2/.venv/bin/python`，从node12运行。避免同时启动两个控制器；创建本目录 `STOP` 可停止分发并关闭本控制器拥有的工作进程，恢复前删除它。权重和来源冻结校验不通过时必须先调查，不可直接覆盖记录。

生成按剩余权重动态分配并发，每组初始2路，收尾可增加；解码／评分利用空卡交错进行，避免固定卡分片等待。每组10个评分分片，全256条特征合并计算FID/FVD，不平均分片分数。部分检测不可测按原覆盖与N/A规则保留。

- `PREPARED.json`：配置／代码冻结；`CPU_ACCEPTANCE.json`：样本、分片、复用及两机资源检查。

- `RESULTS.md`／`RESULTS.json`：已完成组的实际成绩；`COMPLETE.json`：全部完成收据。
- `controller.log`／`logs/`：控制器及各任务日志；失败详见 `FAILURE_*.json`。
