# GLARE去额外门槛版（RGB检测）

用户要求在严格版之外增加去掉额外质检门槛的结果。本版不覆盖严格版、不重新生成音视频，复用816个独立视频的已验证RGB检测原始输出。

## 实施口径

- 取消整段100%检测成功、唯一FER人脸、FER与MediaPipe框IoU≥0.1的准入门槛；全部train24/test24、八条件、双seed进入评分，不因检测覆盖率取子集。
- FER多脸采用原FER Video默认的first_face_only语义，选择检测器返回的第一张脸；无脸行保留空情绪值，交由既有反应规则按0读取。完整原始多脸结果仍保留。
- MediaPipe原始pickle不改，沿用既有反应规则的detected mask、姿态缺口插值、平滑和事件门槛。不另加补帧或阈值。
- 保留RGB修复、反应参数、GLARE四项公式、权重、输入、seed、视频时间轴。仍检查文件哈希、配对身份、帧数和有限数值；这些检查防止错文件或损坏数据，不是检测质量筛选。
- 各条件均按24条/seed独立评分，再平均两个seed。没有匹配事件的R-ATD等仍可为N/A，不人为填零。
- FVD/UTMOS/SyncNet结果及有效范围保持现状，仅增加GLARE口径切换。

## 参考代码核对与更正

先前将100%检测筛选笼统称为仅本项目添加，不够准确：参考标注工具的`related/visual_reaction_annotation/generate_usable.py`也排除FER不完整和MediaPipe detection_rate!=1的片段。GLARE评测公式本身只读取反应CSV。因此本版明确叫“去额外门槛诊断版”，不是“官方标准全量评测”。

既有smiling等规则将缺失FER情绪按0读取、以MediaPipe detected mask调制原信号；nodding/head_shaking先插值姿态，再按detected mask调制并平滑。缺失信号会影响反应分数，结果须连同漏检诊断解释，不能等同人工真值。

## 方案与验收

按用户指定采用取消准入门槛、沿用既有规则的方案；不改为人工标注，也不引入新的有效区间评分公式。代码独立版本保存，原严格版保留。

验收：816个视频全部产出帧数一致的反应CSV；原严格通过视频的新旧CSV完全一致；16个条件各48配对，无静默丢样本；全部GLARE评分完成；HTML可切换严格/去门槛两版，数值和覆盖率与报告一致，原音视频播放不变。
