单网卡在完整预热后做A–B–B–A，结果见 `single_exact/RESULTS.json`。最初 `eight_exact` 仅完成预热便为恢复训练中止，不作最终证据。用户随后明确要求完成八网卡测试，`eight_only/RESULTS.json` 完成独立进程预热＋两轮原执行测速，每轮均从同一224步、相同6个后续批次比较；没有再次混入缓冲或优化器变化。网络比较是两次同批重复，并非跨网络ABBA；样本数有限，3.34%是本次测量，不能保证所有批次均同幅度获益。

各轮都有两次最长11.95秒真实更新并恢复原224步，再开始6个匹配批次；八网卡峰值129.6543GiB，未OOM。八网卡各轮全部可训练参数与Adam相对同网络预热参考逐值相同；跨网络AV损失差小于1e-12。FP64 SUM和优化器保持不变，不能将网络内逐值相同误述成跨网络参数已逐值比对。

阶段计时是各阶段独立的跨rank最大值，不能相加；reduce含较少微批rank等待较多微批rank的时间，不是纯网络耗时。设备端口计数器在容器内不可读；网卡设置以启动配置及运行进程环境核对，不声称已有逐端口流量验证。
