目标：提高真实生产的持续总吞吐；输入、模型、prompt、裁框、官方音频净化、输出长度和点头阈值不变。不能用单卡8条测试替代验收。

若提高并发未产生可重复的总吞吐收益，则回退，继续定位。配置修改仅限并发；以同一运行中的多次全局窗口验收，保留全部成功标签与证据。无需重做已完成标注，也不恢复goal或定时消息。
