# 新观察式prompt：50条配对验证结果

**结论：新观察式prompt明显减少了推演措辞，但没有彻底解决推演、短区间重复和输出可靠性问题，尚不支持直接取消后处理。**

- 本轮旧／新两组中，含明确推演词线索的有效请求占比为98.3%／14.9%。该检查是固定关键词诊断，不是心理推演的人工准确率。
- 短于0.2秒的候选比例从67.0%降至53.5%，但候选时长中位数仍为0.133秒；同次请求中的同文额外条目仍大量存在，不能认定持续事件划分已修复。
- 50条均有有效事件输出，但新组有12个请求未通过校验，其中2个输出截断；旧组为6个未通过。失败原文全部保留。
- 动作覆盖不能靠词频判断。新组没有直接使用nod，但S0260的w003仍分别描述head tilts slightly downward和head tilts slightly upward；这类运动是否为真实点头需要回看视频。没有逐帧真值，不能声称点头全部漏检，也不能声称完整保留。

具体例子见[原文对照](REVIEW_NOTES.md)：S1103保留持续微笑与手部动作；S2147仍有reflection／thought等解释；S1032整段仍交替重复两句嘴部描述，共52条。

本轮不执行方案A、不对原始新输出去重或改写、不覆盖正式标签。该prompt可保留作下一步候选，但其原始输出还不能直接视为最终训练标签。

仅测试观察式视觉打标prompt，未执行方案A文本整理。新50h同一批50条，Qwen3-VL-8B-Instruct；512×512、8fps、整段＋3秒窗口／1秒步长。新旧两组均本轮重新运行，每组293次输出；模型、schema与生成参数一致。完整prompt和复现命令见[README](README.md)。

## 统计

只有通过原有字段与时间校验的响应进入描述统计。原始失败输出保留，不自动修补。推演关键词仅是线索，不是人工准确率；例如as if speaking可能是对嘴部动作的不确定描述，并不一定是心理推断。候选数含重叠窗口，尚未合并去重。

|---|---:|---:|
| 结构与时间校验通过 | 287 / 293（98.0%） | 281 / 293（95.9%） |
| 输出截断 | 0 | 2 |

| 含明确推演词线索的请求 | 282 / 287（98.3%） | 42 / 281（14.9%） |
| 含广义推演线索的请求 | 282 / 287（98.3%） | 46 / 281（16.4%） |
| 含广义推演线索的样本 | 50 | 24 |
| 有效原始候选数 | 1,786 | 1,212 |
| 含明确推演词线索的候选 | 1,265 / 1,786（70.8%） | 57 / 1,212（4.7%） |

“明确线索”包括indicating、suggesting、implying、signalling、conveying、as if、perhaps、possibly；广义检查还包括attentive、engagement、amusement等。完整正则见analyze.py。重复原文不自动等于同一次事件，小于0.2秒也不自动等于错误。

## 复现与对照边界

50条成员和全部媒体帧摘要均与上轮相同。旧prompt的293个重跑请求中，210个与上轮原文逐字相同，83个有变化；因此本轮以同期旧prompt作为主要对照。temperature=0不保证不同批内生成过程中的输出逐位一致，差异的具体数值原因未单独归因。

这次同时更换了任务表述与持续事件划分要求，衡量的是整个候选prompt，不能单独声称删除backchannel一词导致某个收益。观察式描述仍需判断哪些适合作为最终backchannel标签；普通眨眼和嘴部动作并不自动具有回应意义。

没有逐帧人工边界真值，不能给出准确率、召回率或保证±0.2秒达标。未覆盖正式标注、训练标签或缓存。
