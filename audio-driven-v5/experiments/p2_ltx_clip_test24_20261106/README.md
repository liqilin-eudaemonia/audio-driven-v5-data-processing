## 本轮修复

1. 新增三机24卡命令生成，同时保留四机32卡入口。
2. 修复控制端传入相对配置路径、远端切换目录后找不到文件的问题。配置和resume路径统一转成绝对路径；三机/四机均加入回归。
3. 最长样本快照范围显式限制为训练参数与buffer。进一步核对确认，当前实现原本已把冻结LTX排除在state_dict之外，因此这项属于边界加固，不计入实测提速收益。此前关于会复制整套冻结LTX的判断已更正。

首次失败只发生在读取相对配置路径时，未进入模型训练。失败日志保存在`launch/`；成功完整运行日志在`launch_absolute/`。
