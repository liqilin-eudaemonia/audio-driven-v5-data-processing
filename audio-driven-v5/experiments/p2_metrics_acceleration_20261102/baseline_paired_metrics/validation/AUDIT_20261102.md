# 指标计算独立复核（2026-11-02）

结论：上一版的 smoke test 证明运行链路可用，但不足以证明与参考实现一致。本轮发现并修复两处预处理差异，补充独立数值与上游加载路径对照。修订版可用于文档中固定协议的实验比较，不能声称与 AnyTalker Table 1 完全等价。

## 修复内容

1. **FVD 缩放口径不一致。**上一版使用 OpenCV INTER_AREA，原框架使用 PyTorch bilinear、align_corners=False、round 后转 uint8。对非 224 输入存在差异；上一轮 224×224 自检未覆盖该条件。现在直接调用原框架 `batch_to_bcthw_uint8`，并在 contract 中记录该依赖文件的 SHA256。
2. **DeepFace 预处理顺序不完全一致。**原代码先缩放 uint8、再归一化；官方 analyze 先归一化、再浮点缩放。已修正。所测同一人脸裁图的七类概率最大差异从约 0.05348 个百分点降至 0.00000319 个百分点；两版该样本 argmax 均为 sad，但不能据此认为所有临界样本都不受影响。
3. 统一 Torch 输入为 contiguous NCHW，与参考路径一致，避免内存布局导致的微小浮点差异。修正 ΔResp 文档公式引用：ΔResp 为正文式 (4)，Emo-Acc/Div 才是附录式 (8)–(9)。

旧验收报告保留原代码哈希。若曾用旧版在非 224 视频上报告 FVD，需重算；正式报告表情指标也应统一使用修订后的预处理，不能混用版本。

## 实际核对结果

| 检查 | 结果 |
|---|---|
| PSNR | 与 skimage PSNR 比较，3 种尺寸一致至小数点后 12 位 |
| SSIM | 独立用 OpenCV 高斯卷积按公式计算，与当前实现一致至小数点后 12 位 |
| Fréchet 距离 | 5 组不同 N/M/D，覆盖低秩、满秩、样本／总体协方差；与 SciPy sqrtm、官方 pytorch-fid 结果在数值容差内一致 |
| 秩 1 协方差 | 额外用解析闭式验证至小数点后 10 位，避免只依赖奇异矩阵上的 sqrtm 数值结果 |
| LPIPS | 与官方默认预训练构造器对照：全部 state_dict 权重一致，测试分数差为 0 |
| FID 特征 | 与官方 PNG→ToTensor→Inception pool3 路径对照：2048 维特征最大差为 0 |
| FVD 特征 | 32 帧、320×480 输入，与原框架预处理＋加载器＋同一 I3D 对照：最大差为 0 |
| DeepFace | 同一检测裁图与官方 analyze(skip 检测、align=False) 比较：最大概率差约 3.19e-6 个百分点，类别相同 |
| ΔResp | 用论文索引及显式双重循环独立算式 (4)，与向量化结果一致至小数点后 12 位 |
| 数据集汇总 | 用不同长度两段检查：Emo-Acc 为 9/12=0.75，而非片段均值 0.5；Emo-Div 为 (3+1)/2=2；ΔResp 为 (3×1+1×3)/4=1.5 |

扩展后 **15 项回归测试通过**。真实模型交叉对照结果：[reference_audit_20261102.json](reference_audit_20261102.json)。检测器与概率模型运行在 CPU，未启动全量评测。

Fréchet 数值容差：rtol=1e-7、atol=1e-6。高度奇异的 128 维、2 样本案例中，SciPy sqrtm 与低秩计算存在约 2.08e-5 的绝对差（分数约 344）；解析秩 1 检查支持低秩实现，并非将此数值差误作公式错误。

## 仍须遵守的使用边界

- FVD 的**时序协议仍需固定**：新入口默认 32 帧／stride 1，旧入口默认 256 帧／stride 3；现在空间预处理一致也不意味着不同采样配置的分数可互比。
- Emo-Acc/Div 是 DeepFace 分类器一致率及类别数，不是人工情绪真值。当前明确采用 InsightFace 检脸、无旋转对齐；同裁图模型输出对齐不等于复现未知的论文完整检脸管线。
- ΔResp 的阶段加权公式与论文一致，但移动裁框、缺失帧支持是已记录的本地适配；它只描述眼眉区域的平均运动幅度。不同轨迹可以同分，不能证明点头次数或回应时机正确。
- 帧索引配对要求视频从相同时刻开始，身份、裁框及 FPS 正确；代码不会自动纠正输入错位。漏脸覆盖率必须与分数一起检查。
- PSNR 采用逐帧分数平均；若包含完全相同的帧，数学上可能为 inf。这是已声明的汇总口径，不应截成一个虚假的有限高分。

```bash
export PYTHONPATH=/private/liqi_workspace/.cache/paired_video_metrics/python
export OPENBLAS_NUM_THREADS=2

/private/software/conda/envs/AnyTalker/bin/python -m unittest \
  evaluation.video.paired_metrics.test_core \
  evaluation.video.paired_metrics.test_reference -v

/private/software/conda/envs/AnyTalker/bin/python \
  -m evaluation.video.paired_metrics.audit_backends \
  --assets evaluation/video/paired_metrics/assets.local.json \
  --face-video /private/liqi_workspace/.cache/paired_video_metrics/smoke_20261101/face0.mp4 \
  --output /path/to/new_reference_audit.json
```

独立上游实现：[pytorch-fid](https://github.com/mseitzer/pytorch-fid)、[LPIPS](https://github.com/richzhang/PerceptualSimilarity)。AnyTalker 公式以本地论文第 6、20 页为依据，检测工具参考 [官方 benchmark](https://github.com/HKUST-C4G/AnyTalker/tree/main/benchmark)。
