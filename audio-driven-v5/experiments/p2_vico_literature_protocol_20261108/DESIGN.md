# ViCo 文献协议对齐：执行设计

用户已要求实施，以 DIM Table 1 → INFP Table 3 → Avatar Forcing Table 4 的明确引用链为优先依据。既有本地适配结果只读保留；不重训基线，不按本次分数选择评价协议。

## 已确定的选择

- 主目标为 DIM/INFP 的 EMOCA 动作表。BFM/L1 文献表属于另一套协议，不与本表混用。既有 DECA 只用于数学实现的诊断，不能写成 EMOCA 实测。
- EMOCA 型号采用 DIM 发布预处理指定的 `EMOCA_v2_lr_mse_20`，输出顺序是 pose6 后接 exp50，未经统计归一化。模型、配置、裁脸路径和执行版本分别留指纹。
- 我们固定使用已生成的联合8000/base-Qwen 与联合8000/SFT2752 两组 test43 视频；同一套原始 GT/speaker。选择发生在查看新协议成绩之前。不通过重新生成、GT择优、删困难片段追分。
- 完整43条、无OOD为默认实测范围。另将 DIM 公开加载器的 audio-key 合并、5至1024帧限制、三个流最短长度规则逐项投影成诊断清单，不能称这个推测清单就是作者发表时的实际test。
- 评分直接使用固定commit的 DIM 函数，并与独立结构化实现核验。FD/P-FD/MSE按片段等权；发布代码的SID使用GT拟合的全测试帧KMeans，exp40/pose20，预测直方图以log2计熵；Var是跨帧和系数拉平后的总体方差；rPCC是拉平后的相关系数差。
- 显式记录原文SID“每序列”文字与发布代码全局聚合的差异。不能将官方代码等同于已证实的发表设置。
- 发布tester去掉listener首帧，同时取speaker前T−1帧。其偏移单独记录；不进行DTW或按GT估计时延。
- 我们实测为RGB视频重新提取，原表基线主要为原生预测系数。两种读出来源保留说明，不借统一维数掩盖差异。

## 未确认项及处理

DIM实际有效test名单/帧区间、默认常量speaker路径是否用于论文主表、十次GT择优是否用于主表，均未确认。默认不复制常量speaker，也不GT择优。所有不确定项进入“原论文／公开实现／本次执行／依据／差异”矩阵。

官方EMOCA下载脚本要求先注册EMOCA与FLAME并接受许可。用户随后确认“我已经完成了，你可以自行下载吗？”，确认记录保存在LICENSE_CONFIRMATION.json；已开始从官方地址获取指定权重。

## 执行与验收

1. 固定论文PDF、官方源码及文献每行来源，生成JSON/CSV/LaTeX参考表。
2. 逐条核对43个UUID、媒体长度和重复audio-key映射，输出公开加载器差异。
3. 验证结构化指标与未修改官方函数一致；真实DECA数组仅用作数学诊断并明确标记。
4. 注册完成后获取官方权重，严格核验编码器全量张量及官方前向、裁剪对照。
5. 仅用此前分配的node11 GPU7、两CPU计算线程，确认容量后提取全部speaker/GT和两组预测；可断点续跑，旧结果不写入。
6. 计算EMOCA指标、GT统计和完整覆盖，生成协议对照表及参考／实测分组表。只有证据支持的可比性才能写入结论，不把缺失的发表细节写成已经对齐。
7. 验收源码、权重、全部样本与评分指纹及可复算性，更新总索引。未完成特征提取不报告EMOCA正式分数。

选择理由：该引用链明确且覆盖多种相关方法。另选BFM/L1主表虽可复用已有特征，但不能回答用户指定的EMOCA引用对齐；继续只做本地DECA统一表也不能替代本任务。
