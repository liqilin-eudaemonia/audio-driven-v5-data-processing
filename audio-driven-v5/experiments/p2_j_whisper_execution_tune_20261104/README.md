# Whisper AV：32卡同批次执行优化

**结果已确定并接续到[新正式运行](../p2_j_qwen_whisper_av_tuned_20261104/README.md)：** 全重算＋256MiB同批平均5.0634秒／步，相对32MiB的5.4357秒减少6.85%。四分之三重算平均4.8221秒，但峰值预留显存133.998GiB，未满足预设128GiB门槛。各组首批完整梯度及16步损失一致。正式进度以新运行实时文件为准。

正式训练保留第209步完整检查点，测速不计入8,927步预算。用同一后续512个样本／噪声位置、固定模型权重、驻留GPU的完整Adam状态，在四机32卡比较：

| 方案 | 重计算 | FP64通信桶 |
|---|---|---|
| all32 | 全层 | 32MiB |
| all256 | 全层 | 256MiB |
| three_quarters256 | 四分之三层 | 256MiB |

每组先用最长片段执行完整前后向、FP64归约、裁剪及零学习率Adam更新，再预热并计时16步。Adam采用零学习率，仅在测速进程中更新动量；正式模型及优化器检查点不变。每组重新恢复动量和独立CPU step标量，避免修改mmap原检查点。最长／计时窗口峰值均不得超过128GiB，allocator限制为134GiB；OOM候选分流，不进入正式配置。

对首个计时batch逐rank比较完整裁剪梯度SHA，并比较16步全局损失的逐值一致性。仅采用安全、梯度／损失一致且较同批基线快至少5%的方案。失败、停止或没有合格收益时自动恢复旧源码中的行政迁移校验器及原训练，并保留所有测试结果。
