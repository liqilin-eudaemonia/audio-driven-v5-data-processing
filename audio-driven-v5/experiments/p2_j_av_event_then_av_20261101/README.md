## 正式续训显存调整

恢复后的第4,221步出现两卡等待、其余卡同步停滞，未输出明确OOM堆栈。将运行时PyTorch显存上限从128GiB提高至134GiB，从完整4,201步权重重跑后，第4,221步用7.55秒完成，rank0峰值保留显存133.88GiB，随后继续推进。数据、目标、参数和优化器未改；仅AV后续队列也使用134GiB上限。此结果支持显存上限相关的判断，但未取得原故障的显式异常堆栈。[恢复核验](RECOVERY_4220.json)
