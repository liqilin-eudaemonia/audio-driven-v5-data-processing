# 训练集随机24条：四组最终权重快速对照

**后续音频核查：这些输出大多近静音，UTMOS/SyncNet差值不足以证明有效发声质量变化。训练确含listener音频监督，见[核查记录](../p2_test24_fourway_eval_20261027/audio_investigation.md)。原始数值与输出保留。**

**结论：本轮没有得到“Event监督使实际生成更会回应speaker”的可靠证据；Feature分支也没有显示一致收益，并出现音质下降信号。** 这不是证明Event无效：独立反应检测覆盖不足、GT标注不一致、仅训练集小样本，都限制了结论。当前不应宣布四组中哪组“最会回应”。

具体看配对结果：

- **AV → AV＋Event：** FVD-32降低29.10（约3.6%），UTMOS基本不变（−0.004）；LSE-D增加0.600，LSE-C仅增加0.031且区间跨0。质量指标方向混合，反应R-F1没有改善信号。
- **AV＋Feature → AV＋Event＋Feature：** FVD-32增加11.03，UTMOS增加0.065但区间跨0；LSE-D降低1.050，但LSE-C没有同步改善。不能只选LSE-D宣布总体更好。
- **Feature的影响：** 无Event时UTMOS下降0.131，组级95%区间为[−0.273, −0.006]；有Event时下降0.061，区间为[−0.126, −0.036]。这是本训练子集上的音质指标退化信号，不是跨数据/训练seed的最终结论。FVD收益随Event配置改变，未见稳定的全面收益。

工程决策上，继续保留AV质量基线与AV＋Event主对照，暂不把Feature作为已证明更优的默认分支。接下来优先校准反应检测与独立音频事件时机，补speaker替换和盲评，并在独立dev/test上复验；不能凭本轮结果直接认定H1成立或被否定。


本报告为 **训练集诊断**，不是 dev/test 泛化评测。随机种子20261027，从共同训练集30,415段无放回抽取24段、152.261秒、10个group_id；没有为凑类别挑样本。每组生成seed=137、251，共192条全部成功。四组最终checkpoint均为第1,268步，训练seed=20261023、global batch=24。

四组数据/目标、基座资产、数值配置、LoRA、共享参数初始化一致，见 [配对核验](pairing_audit.json)。Feature指0.1×视频Feature＋0.1×音频Feature；Event系数0.05。E0的事件头仅作detach(U)诊断；四组LoRA均由AV梯度更新。使用训练时原音轨，没有替换为后来全量静音版本。

## 对照原实验计划

| 原计划要验证的内容 | 本次证据 | 当前能否得出结论 |
|---|---|---|
| 共同初始化、数据、预算的E0/E1成对实验 | 四组最终权重及192条同输入/seed输出已核验 | 工程对照成立 |
| Event使实际生成的反应和时机改善 | 有GLARE独立检测，但共同集仅5条、每组仅1–2次匹配 | 不足以支持或否定H1 |
| 七类与音频回应的事件时机 | GLARE只覆盖视觉六类；未取得独立音频事件真值 | 不能声称音频回应改善 |
| 无事件区间误触发护栏 | 没有人工确认的负区间 | 未验证；不能用更少/更多动作代替 |
| 自然度、角色、身份、音频质量护栏 | FVD/UTMOS/SyncNet及输出可检查；盲看页已生成 | 自动质量诊断可比较，人工自然度护栏尚未验证 |
| speaker替换后的响应适当性（§8.4） | 此轮按用户要求跑正常输入24条快速验证，未执行audio_swap/盲评 | 未验证是否真正更理解speaker |
| 独立dev/test与第二训练seed复验 | 本轮均为训练样本、一个训练seed | 无泛化或稳定收益结论 |
