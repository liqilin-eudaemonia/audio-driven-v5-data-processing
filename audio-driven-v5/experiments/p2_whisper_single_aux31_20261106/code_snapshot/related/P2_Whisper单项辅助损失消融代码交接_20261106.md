代码、配置及CPU验收已完成。按用户后续授权，已启动四机31卡顺序队列：等待当前规划LoRA释放指定卡后，先Event＋Whisper，再Feature＋Whisper；node8物理GPU7始终预留。实时进度以队列状态为准，不能把排队当作已开训。

## 两组实验与固定条件

| 实验 | 实际训练目标 | 辅助分支 |
|---|---|---|
| Event＋Whisper | AV＋0.05 Event | 19类整段多标签BCE，梯度回到Connector；不构建Feature decoder，不读取teacher |
| Feature＋Whisper | AV＋0.025 video Feature＋0.025 audio Feature | 两路EmbeddingDecoder的flow-matching特征重建；Event头冻结且不执行，不读逐条Event目标 |

Feature不是直接对Qwen H做MSE。两组的Whisper都只编码speaker audio，经适配器及独立视听cross-attention残差注入LTX，Whisper分支由AV loss训练。Qwen、Gemma、Whisper encoder、teacher与LTX主体冻结；训练Connector、LTX文本LoRA、Whisper适配器及残差分支，以及该组启用的一种辅助头，共4组参数。

Event／Feature两个字段的系数在通用配置中保留历史标量，是否执行由loss模式决定；实际禁用分支没有损失和优化器更新。`inspect`命令显示实际生效公式。

参照实验为`experiments/p2_j_whisper_event_feature_train31_20261105/config.json`，从同一预训练初始化与seed20261023重新开始，不从联合实验8000步继续。复用旧500h的285638条train候选池、原始未SFT Qwen H、指导文本Gemma、最终512修正版裁框、官方时间并集净化的listener AV、原19类Event和speaker Whisper缓存。未切换到重选或重标的新数据。

- 4机31卡，8＋8＋8＋7，node8物理GPU7预留；global batch31。
- 两组均训练8000步，每500步保存完整模型、Adam与31份RNG。6000和8000检查点用于后续同清单评测。
- 每组248000次样本展示，8000步不是完整500h的一轮。285638条完整一轮的历史预算是9215步。
- 严格复用原9215步时长计划的前248000个`(sample index, noise ordinal)`，包含原计划跨越第8000步的分组边界；没有重新生成一个8000步计划，避免末尾窗口排序改变。
- 沿用prefetch2、512MiB streaming FP64 SUM、全层梯度重算、BF16前后向／FP32可训练参数、GPU Adam。学习率和50步warmup不变。
- 旧32卡基线的batch差异仍存在；这两组与当前31卡联合实验的初始权重、样本／噪声顺序和更新预算对齐。

在项目根目录执行，`PY`指原生训练环境：

```bash

```

preflight复用已完成的285638条全量收据审计，重新核对本组来源、缓存身份、数据成员与采样计划，不重新扫描全部媒体。运行时每条实际读取仍执行原缓存完整性与身份校验。

正式启动必须显式执行，一次一组；两组启动器共用独占锁，拒绝同时占用同31卡。启动前核对授权卡空闲，不能驱逐其他任务：

```bash
"$PY" scripts/p2_whisper_ablation.py launch --arm event \
  --logs experiments/p2_whisper_event_20261106/launch_01
# Event组结束后，再显式启动Feature组：
"$PY" scripts/p2_whisper_ablation.py launch --arm feature \
  --logs experiments/p2_whisper_feature_20261106/launch_01
```

入口复用已验证的异构8＋8＋8＋7 rank分配；仅在调用期间替换启动器路径，随后还原，不改变旧入口行为。正式开训会先进行最长真实片段的两次完整反向／Adam显存检查，恢复初始参数及RNG后才开始正式步数。Event组已完成31卡最长片段两次真实反传／Adam检查与正式启动验收；Feature组需等轮到该组后再做自己的GPU验收。

停止：在对应输出目录创建`STOP`，当前完整更新后保存退出。恢复：同一launch命令增加`--resume <该目录下完整step_XXXXXX.pt>`，并确认用户STOP已按意愿解除；恢复模型／Adam／rank RNG与同一计划。顺序队列支持同一组完整检查点的最多5次故障恢复；没有自动评测。队列STOP位于`experiments/p2_whisper_single_aux31_20261106/STOP`，会让当前训练完整保存后退出，并阻止后续实验。若在最初完整step0检查点生成前失败，则要求先检查诊断，不会擅自清除run身份从头重跑。
