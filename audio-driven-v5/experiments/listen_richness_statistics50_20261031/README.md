## 数量怎么读

1. `literal`：原文明示次数，例如“nods twice”。时间数字不作次数。
2. `derived_from_distinct_mentions`：原文明确描述第一次及之后另一次，统计为2次，但与明示总次数分开列。
3. `multiple_unspecified / unknown / partial_literal_not_total`：多次但无总数、完全未明确次数、或只描述了局部次数。数值为null；CSV为空或显示“未知”，不是零。
4. `state_group`：同一片段同一持续状态的描述归并为1组；不是实测状态发生一次。音频持续发声仍属于发声次数未知，不按视觉状态组计数。

“含该类片段数”“有依据的次数”“状态组数”是三种不同单位。按类别的覆盖时长是含该行为片段的整段时长，不是行为自身持续时长。视觉事件没有新造时间戳。

## 实现边界

- 本轮复用Qwen3-30B-A3B的v3响应，来源是[原50段试验](../listen_richness_gpu7_pilot_20261031/README.md)。没有重跑LLM。
- CPU只对明确同义名称增加统计键；原模型名称、原句、引用和失败原因原样保留。中文显示名仅用于看表，不是固定类别强制映射。
- 普通静止姿态、稳定注视和中性表情另存，不增加采用类型数。显式否定不作正例。
- 对缺少动作依据、可能将点头机械过程重复记为倾头、全静音却声称发声等情况，保留原项并标为待核；不擅自替换成另一种动作。
- 未识别的新行为名称仍能保留，次数缺少可校验依据时为未知，不强行塞入七类。
- 代码不能补齐LLM未提取的全部行为。本次表格校验通过，不等于语义完全正确。例如S0476提取误写“调整眼镜”后被列为待核，但没有自动新增原文中的“碰鼻子”；S5043把点头写成倾头的记录也只标疑问，不自动改成点头。原文和检测器证据仍可复核。
- 明示次数与分次推得次数是文字证据统计，不是视频真值。全量推广前还需确认类型别名、局部待核与遗漏的处理口径。

## 后续怎么筛选

先按原始人脸、画质、train/test隔离和源时间不重叠要求确定候选，再按相近时长内的采用类型数、已知各类次数和人脸大小比较。未知次数不填零，片段保留为补充候选。主体集选丰富片段，再用类别汇总表检查不足的类别并补充；同一类次数加分需封顶。当前未指定新的目标时长，**没有执行训练子集选择或修改训练准入**。
