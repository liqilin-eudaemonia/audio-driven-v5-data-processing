# Seamless200：六个消融问题

同一200条test片段、同一seed137、512×512/25fps、30步Euler与CFG3/7。下表是总体点估计；FID/FVD从全部样本特征合并计算。各训练组的时长分组启用时刻不同，因此不能把差异全部归因于单个组件。

| 问题 | 主要对照 | 当前判断 |
|---|---|---|
| 只加Event是否有用 | AV6000→Event6000；AV8927→Event8927 | 6000步总体变化小，表情一致率下降；最终步PSNR/SSIM/LPIPS更好。收益依赖训练进度，不能说全面改善。 |
| 只加Feature是否有用 | AV6000→Feature6000；AV8927→Feature8927 | 图像相似度改善较明确；没有证据说明动作或表情同步全面改善。 |
| Event＋Feature是否最好 | 组合7000→Event6000／Feature6000 | 组合SSIM、LPIPS点估计领先，但FID/FVD不占优；相对Feature6000的成对差异区间均跨零。尚不能确认叠加收益。 |
| 只LoRA Qwen是否有用 | 原生Qwen＋Event6000→SFT Qwen＋同一Event6000 | 无需重训LTX，表情一致率与发声召回提高；像素相似度下降，静音片段误发声增加。这里推理文本和H同时变化，不能称为仅改规划文本。 |
| 用SFT Qwen提取训练H是否有用 | SFT规划器＋原始H训练Event6000→同一SFT规划器＋SFT H训练Event6000 | 表情一致率点估计提高，但区间跨零；LPIPS与动作幅度误差恶化。当前不支持普遍更好。 |
| 额外speaker Whisper cross-attention是否有用 | AV6000→Whisper6000；Whisper8000作为进展参考 | 已安排同200条补测，等待授权28卡空闲后自动运行；当前十组没有该分支，不能提前下结论。 |

## Qwen对照的准确含义

- 原始H／SFT H指训练LTX时使用哪个冻结Qwen产生的条件；这些组没有联合更新Qwen。
- “SFT规划器＋原始H Event”沿用同一原始H训练的LTX权重，推理时换成SFT Qwen，因此**生成规划文本和推理H一起变化**。
- 比较两种训练H时，两组推理均使用相同SFT规划文本、Gemma和H缓存；仍需承认训练调度不同。
- 本轮Qwen LoRA是Qwen2.5-Omni-3B规划SFT；数据打标使用的Qwen3-Omni-30B属于另一环节。
- 所有基线本来已通过Qwen接收speaker audio。Whisper实验保留原Qwen H与Gemma文本，另加独立音频／视频cross-attention残差分支，不是有无speaker输入的对照。

## 音频与覆盖率

声学GT有声134条、无声66条。原生Qwen组有声GT整段漏声约94%–95.5%；SFT推理组降至约62.7%–67.2%，但无声GT误发声从5/66增至10–13/66。发声增加不能直接等同内容和时机正确，严格活动F1仍低于3%。

200条视频基础相似度指标有效；情绪199条、动作幅度198–199条有效。UTMOS没有满足质量窗口条件的片段，报告N/A，不计为零。网页绿色／蓝色分别标第一／第二个不同数值，按未舍入值排序、并列同色；颜色不是显著性证明。Emo-Div按与GT的绝对差距排序，生成有声条数只展示不排名。
