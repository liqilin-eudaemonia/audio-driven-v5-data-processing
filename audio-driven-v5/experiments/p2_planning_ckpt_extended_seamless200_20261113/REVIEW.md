# Qwen追加两轮后的规划文字检查

建议先不为找回3000～7000中间权重而重跑训练。7500／8000／8256的规划相对接近；2752与追加两轮后的规划有明显变化，且有改善也有退步，不能认为新权重全面更好。文字接近也不代表hidden states或最终音视频等价。

同一固定诊断200条，原生Qwen＋500／1000／1500／2000／2500／2752／7500／8000／8256，共2000条。复用旧1400条，新增600条；全部非空、正常EOS、零重试。沿用原生加载、同输入和提示、batch16／greedy。没有重训，没有启动LTX新组合。

| 对比 | 200条中逐字相同 | 平均逐词编辑相似度 |
|---|---:|---:|
| 2752 vs 8256 | 5/200 | 50.5% |
| 7500 vs 8000 | 69/200 | 77.5% |
| 7500 vs 8256 | 74/200 | 79.1% |
| 8000 vs 8256 | 92/200 | 83.4% |

以上只衡量表面文字接近程度，不能解释成语义正确率。8000和8256有92条完全相同，但个别样本仍改变发声、点头次数和时间。

## 具体变化

已逐条文字复核预先抽取24条（core48中12条、其他12条），另看先前4个问题样本，共26条；使用自动标注作为比较参考，未重新听看GT确认，不提供全200条语义准确率或统计显著性。

| 页面序号 | 对照结论 |
|---|---|
| 4 | 新版加入Yeah和摇头，比2752的笑声/heh更接近标注，具体次数与次序仍不完全一致。 |
| 7 | 2752反复写Right及点头，约225词；8256约67词，机械重复明显减少，但仍有标注未述笑声。 |
| 82 | 新版删掉2752额外写出的Yeah，仍保留额外点头，属于部分修复。 |
| 1、24 | 标注分别有笑声、Yeah；2752有所保留，三个新权重都改成无声，出现退步。 |
| 56 | 标注四个Yeah；2752写三个，7500/8000一个，8256四个。8256发声次数更近，动作时间仍偏。 |
| 127 | 标注是摇头，四版都写成微笑加点头，主要问题没有随训练消失。 |

具体26条见QUALITATIVE_REVIEW.json。原生模型在这批200条仅33种不同回复、平均12.2词，经常只写保持沉默；它仍可用于hidden来源的对照，但不据此认定其规划质量最好。旧500～2500在六个补充例子中也有各自得失，不能仅按训练步数排出名次。

## 后续选择

优先用2752与8256做音视频组合对比，7500可作末段备选；若保留8000，也只需复用这次规划，成本较低。没有足够证据证明丢失的中期权重会更好，暂不为补存它们重训。这不排除未来发现中期最优的可能。最终依据同一LTX下的音视频成绩选择，每份Qwen必须使用自己的文本及hidden states。
