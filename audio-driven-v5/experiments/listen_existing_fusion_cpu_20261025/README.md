## 输入与输出

只读取既有语义观测、模型语义来源、整段与滑窗ASR文本和词时间。生成函数fuse(sample,decisions,tracks)不读取人工反馈，不读音视频，也不调用模型；生成代码没有5个回归样本的特殊分支。人工反馈仅用于输出后的回归检查，页面的5例筛选也只是导航。

当前172个候选（134视觉、38音频）全部具有有效正时长区间；另2个词只有零时长或无可用有序边界，单列失败，不伪造或均分时间。原始682条观测、130条ASR词证据完整保留。ASR候选索引85个，不能当作真实发声次数。15段没有七类独立候选，不能当作负例。

## 自动规则

- 复用已有模型语义描述与分类；视觉候选沿用已有区间并保留来源风险标记。
- 用完整ASR词序确定候选回应顺序；短多词应答按原转写短句保留，重复词不因时间相接被合并。
- 汇总有效ASR与明确引用原词的音频模型时间，做跨来源候选匹配；选择真实出现过的一组正时长区间，用有序动态规划避免一条宽区间吞掉多次回应。不插值、不等分区间，不直接采用零时长记录。
- 时间明确的短ASR边界提供弱位置约束；长度很长或零时长的记录不作为强位置锚点。同词但在ASR时间支持之外的模型描述单列冲突，不借来凑重复次数。
- 整段ASR某词的所有来源边界都长或紧贴窗口边缘，且只有一种局部有效替代词与其重叠时，选择该替代并明确标记内容冲突；这是通用启发式，并非准确性保证。
- 已有音频模型明确识别笑声、视觉也支持笑声，且重复ASR音节没有音频词语证据时，将音节作为笑声证据，保留拟声信息，不生成多个独立说出的词。
- 通用vocalize描述与词回应关联为证据，冲突的非语言描述单列，不能重复计成多次发声。
- 视听事件分别保留时间，仅建立同时发生关系。原始观测不覆盖、不删除。
