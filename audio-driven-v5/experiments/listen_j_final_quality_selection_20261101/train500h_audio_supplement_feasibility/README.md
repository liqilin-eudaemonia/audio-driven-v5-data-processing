# 500h训练集扩充容量试算

只使用最终画质通过的train；dev/test不并入训练。主体集为原始人脸短边p10≥224px的全部264,054段／462.62585h，包含安静倾听。

补充池只放宽人脸尺寸，画质排除、待核和无人脸的分流保持不变。试算从184≤p10<224中筛取已采用speech、vocalization、audible laughter、humming或chuckling类别的片段，并逐条核对已有音频元数据：官方核心区间非空且处理后波形非零。按p10、p50、类别丰富度降序，sample_id打破同分，取完整片段直到达到500h。

试选补充21,584段／37.37443h，实际最低p10=185.94799px，总计285,638段／500.00028h。按同pair、同listener核对源时间，无区间重叠；最终数据池group_id跨split交集为0。

合计99,578段净化后波形非零，占34.86%；这些片段完整时长172.55h。官方发声区间并集31.55h。非零波形和文字音频类别均不构成人工确认的人声、归属或音质保证。此音频类别门槛只是本次试算的补充池条件，不改写或限制已保存的开放标注。

这是容量核算与候选试选，尚未建立训练manifest、特征缓存或更改准入。沿用最终修正版裁框、原净化配方、speaker配对与原文的后续训练导出仍须使用对应读取链路。
