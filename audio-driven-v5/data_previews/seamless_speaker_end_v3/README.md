# Speaker 结束 V3：在原片段上收紧终点

用户要求“针对本次处理的视频，裁剪到 speaker 说话结束”。本版使用同一批 50 个会话、457 个 V2 片段，没有重新抽样，没有运行新 ASR、VAD 或其他模型。

## 终点规则

对每个原片段 `[start, old_end]`，从原有词级转写中找出与片段有实际时间交集的 speaker 词，取最大的词结束时间，并限制不超过 `old_end`。不额外增加尾部静音。时间交集小于或等于 1 毫秒视为舍入误差，不作为有效词或事件。

这会去掉 speaker 说完后、对方正式接话前的等待区间。话轮内部的停顿保留；原主话轮持有者判定、插话排除、片段起点和空间裁脸框均保留。若原片段因为插话等原因在 speaker 发言中途结束，不跨过原排除边界延长片段。

这里的“speaker 结束”严格指**已有词时间戳给出的结束**，不是人工确认的声学终点。词时间戳不准、漏掉的词、句尾笑声/叹气都会影响这个近似。暂不靠 VAD 空白否定已有转写，也不引入新模型修正。

## 本批变化

- 457 个片段保留；324 个终点缩短，133 个保持原终点。
- 累计缩短 347.732 秒，新总时长 6690.440 秒，约 111.5 分钟。
- 24 个片段裁尾后不足 4 秒，保留并标记，便于与 V2 对照；本次不重新筛掉它们。
- 被删尾部完全包含 23 条反馈候选、76 条无转写发声候选；另有 10 条反馈候选、4 条无转写发声候选被截短。这些只是原规则候选，尚不能当成真实 backchannel 数量。
- 单人脸部保持 512×512、25 FPS；双人对照保持 1024×512；各音轨与视频使用同一新终点。

为快速审阅，本轮直接裁短已经生成的 V2 预览视频，发生变化的文件重新编码一次；空间裁剪框和起点不变，未变化文件及完整会话复用 V2。最终训练素材应使用新时间标注从原始视频/WAV 提取，避免累积编码损失。

## 转写与 VAD

原 V2 实际导出区间内，302 条有正时长的 listener 转写中，108 条（35.8%）与原有 VAD 完全不重叠，124 条（41.1%）的 VAD 覆盖不足一半。统计只针对这 50 个会话的导出区间；不是全库指标，也不是经过听音核实的 VAD 漏检率。

抽查首个会话 listener 的原始 JSON，确认 `metadata:vad` 和 `metadata:transcript` 与使用的索引相同。页面一直使用原有 VAD，没有重新推理。这个抽查确认索引与源标注一致，不能证明标注本身正确。

新版修正旧页面一个展示问题：旧版“Listener 转写”时间轴由 `listener_events` 绘制，混入了 `[VAD only]` 事件；现在第三行只显示真正带有文本的事件，VAD 独立显示。正文仍明确列出无转写发声候选。

当前建议：有词的短反馈优先参考转写，VAD 作为额外发声线索；不要用 VAD 未命中直接判为静音。转写也可能误报、漏词或时间错位，非语言发声还需独立观察。参考 `../seamless_rule_turns_v2/transcript_vad_audit.json`。

## 需要根据审阅继续讨论

1. **严格的 speaker 结束边界与滞后反馈。** Listener 的短反馈可能在 speaker 最后一个词之后开始，也可能跨过这个终点。本版按用户要求严格裁尾；若后续要完整学习这类反馈，需要另行定义有限尾窗或事件保全规则，并防止纳入正式回应。
2. **反馈与简短回答的区分。** “Yeah / Right / Okay”等文本可能是 backchannel，也可能是完整回答。当前词表无法可靠区分语义功能，仍需看上下文。
3. **词尾与非语言声音。** 不加尾部余量时，原词对齐误差可能截得偏紧，句尾笑声也可能被删。审阅时可使用完整会话及旧版对照验证，之后再决定是否增加小余量。
