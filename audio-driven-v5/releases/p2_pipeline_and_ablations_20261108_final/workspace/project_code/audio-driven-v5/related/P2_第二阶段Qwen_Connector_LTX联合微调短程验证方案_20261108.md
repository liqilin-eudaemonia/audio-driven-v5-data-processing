先完成第一种组件消融：仅AV、AV＋Whisper、AV＋Feature、AV＋Event、AV＋Whisper＋Feature＋Event，共五组。依据统一评测选择第一阶段生成架构；分别去掉一个组件的三组消融留待有时间再补充。

当前执行指令仍为：AV＋Whisper到6000步完整保存、校验并退出，随后先统一测评，所有后续自动训练均已取消。第二阶段不插入当前队列。

第二阶段直接联合更新Qwen、Connector和LTX的可训练部分，验证生成端反馈能否改善规划表示与音视频生成之间的配合。用户选择不另设“冻结SFT Qwen，只适配Connector＋LTX”的中间阶段。

历史上已完成冻结SFT2697 Qwen hidden、从头训练Connector＋LTX LoRA的旧500h AV＋Event实验，效果未支持改用SFT hidden训练更优。它不包含生成损失对Qwen的反传，也不等同于本次从已训练生成模型出发的联合微调。参见[历史实验协议](../experiments/p2_response200_feature_sft_event_20261103/README.md)与[评测结果](../experiments/p2_response200_feature_sft_event_20261103/RESULTS.json)。

## 数据与可微路径

- 使用最终284,218段／500.001259小时及最新完整标注，train281,060＋dev3,158、test0；保持现有采样分布。
- Qwen在线前向并保留hidden梯度，不能使用冻结Qwen hidden缓存参与联合更新。
- 训练时使用已有标注计划；评测时使用当前Qwen自己生成的计划，再生成音视频。
- 生成梯度路径：LTX → Connector → Qwen hidden → Qwen LoRA。若保留Feature，其梯度从Connector输出反传；若保留Event，其梯度从LTX生成hidden反传。
- AV VAE、listener teacher、speaker Whisper等不依赖当前Qwen权重的缓存按身份核验后复用。训练中Gemma使用固定标注文本时可复用相应文本缓存；评测时各检查点重新生成自己的计划／Qwen hidden／对应文本条件。
- 联合反传并不会穿过推理时离散的文本采样，因此仍需单独检查自然语言规划能力。

## 短程预算与候选超参数

只开一条最多300步的验证训练，保存step0／100／300。

| 项目 | 讨论确定的初始方案 |
|---|---|
| 有效global batch | 31；显存不足时通过梯度累积维持 |
| 第一次检查 | 100步，约3,100次样本训练 |
| 第二次检查 | 300步，累计约9,300次样本训练 |
| Qwen LoRA学习率 | 候选起点1e-6 |
| 其他可训练模块学习率 | 候选为各自第一阶段学习率的约1/3 |
| 预热 | 前20步 |
| 扩大训练条件 | 300步有明确收益且无明显退步，再考虑约1000步 |

学习率和规划SFT权重是待短测确认的候选参数，不是已经验证的最优值。正式开始前，使用最长真实样本检查显存、完整反传、各模块梯度及真实步速，固定配置后进入正式预算。不得将缓存训练步速直接用于估计在线Qwen联合训练耗时。

## 损失定义

若第一阶段最终选用三个组件齐全的模型：

\[
L=L_{\mathrm{AV}}
+0.025L_{\mathrm{Feature,V}}
+0.025L_{\mathrm{Feature,A}}
+0.05L_{\mathrm{Event}}
+\lambda_{\mathrm{plan}}L_{\mathrm{SFT}}.
\]

Event仍为当前LTX hidden上的整段监督，沿用既有类别、有效类别mask、未知／冲突屏蔽和弱负例规则。若最终生成架构不包含某个辅助组件，移除相应项，不在第二阶段偷偷改变组件对照的定义。

规划SFT沿用现有描述标签，只对回答token计算交叉熵，用来保持Qwen规划能力。`λplan=0.1`作为候选起点，先检查其梯度是否压过生成目标，再冻结权重。规划标签的筛选适用范围、有效回答token归一化和两种目标的具体组合读取方式，需在实现前明确；本方案不要求新增人工打标。

## 固定64条验证样本

从剩余验证数据中按发声／静音、反应类别和时长分层抽取，冻结名单及来源身份。必须排除：

1. 已进入第一阶段500h训练的样本。
2. 已进入规划SFT训练的样本。
3. 与上述训练样本重叠的媒体区间。

不能仅凭split名为dev就认为独立，因为第一阶段500h包含部分原dev。正式测试集留到方案确定后使用。实现时已完成64条清单、训练ID和双方媒体区间排除，并用独立流式审计复核，详见实现与验收文档。

step0／100／300使用完全相同的speaker输入、listener参考首帧、prompt、种子、采样步数和CFG。每个检查点都重新生成自己的规划和hidden，评测实际端到端流程。

## 评测与继续／停止条件

同时观察三方面，并保留逐样本结果：

- **反应执行**：计划中的反应是否实际生成，是否增加无依据的动作或发声；区分“执行了计划”与“反应本身合理”。
- **生成质量**：画面稳定性及音频质量是否退步；64条规模下不依赖FID／FVD单独选择模型。
- **规划能力**：固定验证集的回答交叉熵，以及重复、复述speaker、格式错误等是否恶化。验证交叉熵使用固定参考计划；端到端生成使用模型自己的计划。

100步主要排查明显退化；没有严重问题就继续到300步。300步若反应执行改善，同时规划及生成质量没有明显退步，再考虑扩大到约1000步验证。若没有清晰收益，保留第一阶段模型，不直接投入整轮500h。短程未见收益不等于证明联合微调永久无效，但不足以支持立即扩大投入。

“明显退步／清晰收益”的具体指标、阈值和聚合方式应在查看第二阶段结果前冻结；当前没有讨论确定数值阈值。自动反应检测仅在既有可验证类别范围内使用，不把未校准检测结果当作人工真值。
