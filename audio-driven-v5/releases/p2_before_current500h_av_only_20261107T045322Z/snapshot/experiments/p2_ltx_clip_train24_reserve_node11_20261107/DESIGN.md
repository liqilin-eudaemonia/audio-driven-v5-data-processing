# 三机24卡接续，空出 node11

用户要求先停止四机训练，完整空出 node11 用于推理测评，再在 node12/node8/node4 上续训。沿用上轮已验证的完整检查点迁移；batch24，每卡一条，保留模型、Adam、对应前24个 rank 的 RNG 和全重计算。父检查点保留所有31份 RNG。所有损失、标签、缓存、学习率和 warmup 不变；每500步保存。

保留父调度中未消耗的每个样本及其 noise ordinal，依据父调度 base_step 计算已消耗位置，按时长重新组24条批次，只在末尾补齐不足一批。绝不能用全局 step 直接乘31裁剪第二阶段的调度。总步数按剩余数据重新计算，不重复已消费前缀。

备选是保留batch31并分配不等数量样本，会增加代码和负载不均；本轮沿用用户此前“训练速度优先”的选择，采用原生batch24。验收包括逐值模型和优化器迁移、24份RNG、完整剩余样本核对、节点/GPU隔离、真实多步更新和loss/梯度/速度检查。TensorBoard保留历史。
