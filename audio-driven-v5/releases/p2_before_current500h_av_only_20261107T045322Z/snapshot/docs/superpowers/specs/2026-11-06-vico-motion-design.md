# ViCo 运动指标补测

用户要求补齐已生成联合模型 step8000 的运动评分，并于本轮明确选择以下评分口径：原始系数，TLCC 延迟 ±2 秒逐帧扫描，RWTLCC 4 秒窗口／1 秒步长，逐片段等权汇总。继续使用 node8 物理 GPU7，复用原 test43 视频，不重新生成、不修改已完成画质评分的封存文件。

采用 ViCo 官方仓库 Deep3DFaceRecon 的原始网络、epoch20 权重和 align_img 预处理；三路分别为 speaker、listener GT、prediction。保存完整257维系数、70维运动、关键点、检测成功掩码、对齐参数和输入／权重／代码哈希。批量 FAN 与官方逐图 API 比较，网络批量输出与 batch1 对照；失败则修正，不默默替换提取器。

采用公开定义复现 FD、RTLCC、RWTLCC、FID_delta_fm、SND、V-D；FD 分 exp/angle/trans，其余分 exp/pose。SND=FID_fm+FID_delta_fm，遵循 TH-PAD 的逐片段定义；FID 用无偏样本协方差，V-D 用时间总体方差。相关性使用逐坐标 Pearson 曲线，重叠部分独立去均值，常量坐标置零并计数；窗口只使用完整120帧，尾部不足窗口不补齐。FD 和 FID_delta_fm 展示值乘100，保留原始值。GT自比较应所有距离为0。

考虑过的方案：等待作者完整评分脚本可获得严格实现但目前官方链接为占位；只做四种无需 lag 的指标可减少约定但覆盖不完整。用户选择补全公开定义并透明固定其余细节，不宣称严格复现 CustomListener 表1。

原生生成25FPS、评分副本30FPS，重复帧会影响运动差分和相关性，必须随结果披露；RGB重提取也不等于直接使用3DMM生成模型的原始系数。对齐不得引入时间平移或GT拟合。失败人脸沿用官方前向填充及首帧标准点回退，记录覆盖率，全片无人脸直接失败。

交付：独立 protocol.json、129个视频系数缓存、逐片段和汇总结果、CSV、GPU记录、最终审计及README；六组数值测试和真实小批验证，完成后检查43组全覆盖、三路帧数、有限值、来源哈希、原结果不变、GT自比较和展示倍率。

实施补充：发现1秒与3秒两条短片段后，用户再次确认完整lag／窗口覆盖方案：RTLCC42条、RWTLCC41条，其余43条；不适用条目标N/A。评分修订封存于SCORING_PROTOCOL.json，原提取协议与全部特征回执保持原样，原始源代码按SHA保存于frozen_source。批量及模型内并发FAN未通过重复核验，正式采用顺序FAN和跨进程视频并行。全部评分与独立审计已通过。
