# 50段开放事件整合试验

用户已明确授权按已讨论方案实现并复核，暂不应用全量。选择保守、可追溯的“原始观测→独立事件候选→回应组→训练接口”流程。放弃时间相接即合并；也不采用未经核实的整段ASR作为边界真值。

复用已有模型语义描述与分类，只在同一语义、相近且重叠边界、来源窗口互不冲突时进行跨窗候选去重；不做传递式区间并集。声学/视觉边界分别保存，宽描述仅关联证据，不桥接多个事件。全部ASR词序包括无效边界保留并去重索引，不凭词数推定回应次数。5条用户反馈单独作为可追溯修正，不改原始模型观测。

50段全部导出原始证据、事件候选、组关系、未解决问题和逐字段确认状态。未知时间不造值；未标记时间不是负例；组外包区间不作为正例掩码；本轮training_admitted=false。复核HTML可比较原始与整合结果、播放媒体、提交事件级反馈。

验收：5个人工案例；分开的okay仍为两次；跨窗重复减少且原始来源不丢；同一来源中的重复保留；没有传递桥接；不同模态保持各自时间；缺边界无监督掩码。GPU全量任务不改动。
