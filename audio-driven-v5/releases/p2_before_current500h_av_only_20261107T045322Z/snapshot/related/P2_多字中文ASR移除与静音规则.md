# 多字中文 ASR 移除与静音规则

2026-10-26，版本 `multi-han-asr-mute-v1`。用户在查看单字标注后明确要求：单个字的非英文先保留，其他中文移除并静音对应片段。本轮应用范围仍为固定100条，不直接更改全量训练数据。

## 执行口径

- 只检查整理后有效音频事件中来源为 `ASR_original_text` 的 `text`，不检查视觉描述或音频模型描述所用的语言。
- 每条 ASR 含两个及以上汉字时移出，并将其当前有效 `intervals` 对应采样点置零。使用Unicode汉字属性计数，空格、标点不计入。繁体与粤语汉字包含在内；不会跨事件拼接单字后再删除。
- 单字“嗯／哈／呵／哎”等保留。本轮没有扩大到其他语言或以非ASCII字符一概过滤。
- 此规则可直接由代码确定，不需要另跑文本模型。它是用户指定的数据筛选策略，不构成对原音频噪声成因的确认。
- 只静音事件有效区间，不删除整条数据，不扩展到整句／整段VAD。起点向下、终点向上取整至采样点。
- 请求静音的范围全部置零；在其外侧相邻存活音频上做最多10毫秒平滑淡变，减少硬切造成的爆音。区间和淡变外的采样点逐位保持不变。
- 若其他音频事件与静音区间重叠，同步裁剪其有效区间；全部被覆盖时也移出，保留原始记录。视觉事件不变。
- 原始与上一版处理文件都保留。新音轨、新派生标签单独存储；移出事件保留原文、原时间、移出前有效区间及原因。
