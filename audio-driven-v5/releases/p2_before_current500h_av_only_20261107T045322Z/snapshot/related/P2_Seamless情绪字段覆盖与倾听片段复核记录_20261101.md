# Seamless 情绪字段覆盖与倾听片段复核记录

记录日期：2026-11-01。范围：当前本地原始数据与最新 J 切分、处理及最终画质复筛保留集。本文区分核查事实、用户观察和当前建议，不代表已修改训练或筛选策略。

## 1. 当前判断与建议

用户查看这批 listener 短片段后反馈：**只看倾听阶段的 backchannel，似乎看不出明显的情绪标签信息。**

这些片段更适合描述微笑、点头、皱眉、眼部变化和短发声等可见／可听反应。短暂微笑未必代表快乐，皱眉未必代表愤怒；在上下文有限、反应较弱时，不能直接从动作推出内在情绪。

即使表情不明显，八维分数取最高值仍会产生一个类别。因此，“最高分类别”不等于“存在明显情绪”，更不等于真实心理状态。另外，本轮类别索引映射尚未确认，不能仅凭当前显示名称评价原模型类别预测是否正确。

**当前建议，尚未实施为训练配置：**

- 保留原始情绪字段及来源，作为辅助信息；暂不用于硬筛选，不将候选情绪类别直接写入生成 prompt。
- 训练和数据选择优先使用可信的动作、表情变化、发声回应，以及画质、人脸大小、回应丰富度。
- 暂不为了具备情绪字段而只选 V00、放弃更清晰的数据。
- 不将五段观察推广为“全量情绪字段无用”。若需要情绪监督，先确认类别索引，再对更广泛、具有明显表情的样本复核。

## 2. 原始字段与来源

依据用户提供的本地全量盘点：129,572 条原始参与者片段中，42,948 条 V00 的 NPZ 含情绪字段；当前盘点中的 V01、V02、V03 不含这些字段。此结论限于本地这批 NPZ，不扩展到未来版本或另行发布的 movement 特征。

| 字段 | 形状 | 解释 |
|---|---|---|
| `movement:emotion_scores` | `[T, 8]` | 类别原始分数，可为负数或大于1，不按概率展示 |
| `movement:emotion_valence` | `[T, 1]` | 正负倾向，不能唯一决定具体类别 |
| `movement:emotion_arousal` | `[T, 1]` | 唤醒程度，不等于动作幅度或类别置信度 |
| `movement:EmotionValenceToken` | `[T, 1]` | 量化值，原样保留，不自行解释 token 编号 |
| `movement:EmotionArousalToken` | `[T, 1]` | 同上 |
| `movement:is_valid` | `[T, 1]` | 用于屏蔽无效帧，不是情绪准确性保证 |

这些是 Imitator 模型估计，不是人工情绪真值。各参与者 NPZ 在 `/public/0_DATA/2_Avatar/seamless_interaction/{improvised,naturalistic}/{dev,test,train}/` 下的分片 TAR 中。

参考：[官方字段说明](https://github.com/facebookresearch/seamless_interaction#movementimitator-feature-types)、[本地 SDK README](../../seamless_interaction/README.md)。

## 4. 叠加人脸大小条件

使用整段采样原始人脸短边的 **p10**，不是预裁框边长，也不是缩放后的512像素。

| 条件（最终保留且 V00） | 数量 | 时长 | 划分 |
|---|---:|---:|---|
| 人脸短边 p10 ≥224 px | **8段** | **35.025秒** | 全部 train |
| 人脸短边 p50 ≥224 px | **17段** | **74.8225秒** | 全部 train |

p10 在128–160像素（左闭右开）的有343,284段，在160–192像素的有128,438段。当前 V00 原生人脸总体较小，但不能据此判定每条均不可用：抽样画面仍可辨认主要表情，放大后细节较软，缩放不会增加原始信息。

[满足 p10≥224 的8条明细](../experiments/listen_j_final_quality_selection_20261101/emotion_v00/face_p10_ge224.json)。本次未按该条件重新删数据。

## 5. 五段复核及类别映射限制

五段按人脸尺寸分档、不同来源选择，**不是随机抽样，也不是按情绪强弱选择**。

| 页面序号 | 样本 ID | 人脸 p10（px） | 有效帧／涉及帧 | 整段候选类别（暂定映射） |
|---|---|---:|---:|---|
| 1 | `improvised_V00_S1138_I00000601_local_17bc46eb5c91` | 137.25 | 81／81 | 快乐 |
| 2 | `naturalistic_V00_S0225_I00000486_local_29fe3e761e19` | 157.43 | 209／209 | 悲伤 |
| 3 | `improvised_V00_S0093_I00000307_local_e8eeecede399` | 170.46 | 121／121 | 轻蔑 |
| 4 | `naturalistic_V00_S0121_I00000135_local_3137ffeb7bda` | 182.70 | 336／336 | 中性 |
| 5 | `improvised_V00_S0822_I00000920_local_1ebda932114f` | 225.96 | 87／94 | 愤怒 |

表中类别是规则导出的候选名称，**不是用户逐条确认结果**。用户反馈为整体情绪不明显，尚无逐帧人工情绪真值。

最初仅显示 Valence、Arousal 和八维原值；用户需要明确类别后，暂按官方 README 的列举顺序作索引映射：0愤怒、1轻蔑、2厌恶、3恐惧、4快乐、5中性、6悲伤、7惊讶。

**尚未找到明确的官方逐维索引说明。** 代码保留 `category_name_mapping_verified=false`，页面及字幕注明映射待确认。不能将文档列举顺序说成已经验证的输出顺序。[官方新增词表的提交](https://github.com/facebookresearch/seamless_interaction/commit/6803583c2694)。

计算方式：

- 当前帧：仅在有效且值有限时，取原始八维分数的 argmax。
- 整段：有效帧分数按片段内帧覆盖时长加权平均，再取 argmax；不是多数帧投票。
- 另记录最高分类别的帧占用时长，不将其称为真实情绪持续时间。
- 不平滑、不设“明显情绪”阈值、不将原分数转成置信度；无效帧不赋类。

## 7. 后续使用边界

若继续做情绪监督，先确认原模型的类别索引，再检查有效帧比例及更广泛样本。需要区分“表情类别预测”“主观情绪状态”“训练控制标签”。如另用分类器或VLM判断，应单独注明新标签来源，不能冒充原NPZ字段的确定解释。

当前只完成分析记录和小样本展示，未启动新的情绪预测、全量筛选或训练任务。
