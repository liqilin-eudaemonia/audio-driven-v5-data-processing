## 2. 当前规则和修改范围

沿用 `listen-semantic-prompt-v4.4-extractive`：模型判断语义重复、选择包含可见动作最全面的原句及其原文前缀；代码直接用原文前缀形成描述，仅规范句末标点，去掉indicating／suggesting等推演尾部。保持原主语、时态；原句本身没有主语时不补写。无法安全截取时拒绝，不通过改写补救。

同一语义的重叠观察可以去重，独立发生的动作不能仅因同名合并。保留条目的时间来自选中的单条原始来源，不把多个来源的外包区间当作持续动作。support必须指向keep；检查来源、实际保留quote中的显式动作、时间相交和来源完整性。动作词仅用于遗漏报警，不建立新的类别映射，也不能保证所有语义细节都不遗漏。

**本轮整理的是已有视觉文本，音频事件所有字段完整复制**，包括原词、起止时间、有效区间和重复回应。不会重新ASR、重新静音，也不会把视觉笑容转成声音事件。原始七类标签、开放原文、配方、媒体及缓存均不覆盖。

## 4. 执行与续跑

所有命令在项目根目录执行。输入已准备时直接使用，不重复执行第一条。重建输入必须换新输出目录；失败准备只留下partial文件，不发布PREPARED。

```bash
python scripts/prepare_listener_semantic_subset.py \
  --subset experiments/p2_train50h_postprocessed_reselected_20261027 \
  --output experiments/p2_train50h_semantic_plan_a_20261027/prepared

python scripts/run_listener_semantic_prompt_cluster24.py \
  --inputs experiments/p2_train50h_semantic_plan_a_20261027/prepared/inputs.jsonl \
  --output experiments/p2_train50h_semantic_plan_a_20261027/run \
  --model /private/ckpts/Qwen3-30B-A3B-Instruct-2507 \
  --batch 8 --memory 0.46 --attempts 3

python scripts/audit_listener_semantic_prompt.py \
  --inputs experiments/p2_train50h_semantic_plan_a_20261027/prepared/inputs.jsonl \
  --run experiments/p2_train50h_semantic_plan_a_20261027/run
```

集群脚本使用node17 `172.29.15.91`、node12 `172.29.252.11`、node4 `172.29.225.51`各8卡，每卡一个实例；远端Python固定为 `/private/software/conda/envs/vllm/bin/python`，自动设置libstdc++的LD_PRELOAD。共享项目、权重及SSH密钥必须在节点可访问。

**启动前重新检查24卡显存与其他任务。** `--memory 0.46`是每卡总显存的比例，不是剩余显存比例；该值仅在此前并行小样本验证过，不保证任意其他任务负载都可叠加。不要终止其他训练。CPU输入准备是流式，但现有推理控制器与审计会加载完整JSON输入；原输入约1.1GB，Python对象内存明显更大，启动前检查主机可用内存，不能将1.1GB当作内存上限。

同一输入、模型文件、代码、prompt、重试次数下，重复运行原命令可恢复；不要同时启动两个控制器写同一run。代码或协议变化必须用新目录；禁止跨协议复用原响应。失败样本在相同协议下重跑通常复用已有确定性响应，不意味着自动获得新答案。需要修正规则时另建版本。

## 5. 结果读取和验收

- `results/current__<sample_id>.json`：仅通过程序检查与模型自检的派生事件，保留完整source_record及来源。
- `prompts/current__<sample_id>.txt`：对应可读生成指导文本。
- `attempts/`：模型原始提案、自检和失败依据，**不能当作正式labels目录**。
- `summary.json`：accepted数量、rejected明细和worker状态；`cluster_workers.json`：节点日志及退出状态。
- `audit.json`：CPU重放报告。它验证实现和证据一致，不证明动作识别正确。
- `COMPLETE.json`：仅全体通过才写入。任务已跑完但存在拒绝时，没有该文件是预期行为；必须查看summary，而非把缺文件等同于机器没跑。

小样本100条实测60通过、40拒绝，全部worker正常退出。拒绝原因包括宽区间串联分开的动作、support错误指向、语义自检以及无法安全截取。**不能承诺整套29,975条一次全部通过。** 被拒样本保留原文和提案，不自动丢弃训练成员，也不静默采用提案或回填旧prompt冒充新结果。正式训练切换前必须显式决定这些样本的处置，并记录实际覆盖数量。

## 6. 训练与缓存边界

本轮输出是独立的派生事件／prompt视图，**没有自动修改训练配置或接入新读取器**。接续训练代码按sample_id读取通过结果，核对输入、协议和覆盖，再建立新数据视图；不得覆盖原integrated_labels.jsonl。

- 原视频latent、后处理音频latent、静音配方、speaker输入以及媒体引用继续复用，不新增WAV。
- 七类canonical事件与事件监督缓存本轮未变；不能把新的语义条目数当作已同步修改的七类事件数。
- 使用新描述作为文本条件时，重新生成受其影响的Gemma文本条件、包含计划的Qwen hidden缓存，并使用独立缓存版本；固定文本或完全不含这些描述的条件可在确认依赖后复用。
- 如果以后还要用新事件替换辅助监督，需要另行同步canonical与事件缓存，不能在本轮中隐式发生。
