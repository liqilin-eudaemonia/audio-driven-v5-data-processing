## 一条记录是什么

schema 为 `j-upright-response-sft-reference-v1`。清单只存引用，不复制音视频。

- 条件：配对 speaker 音频片段，加 listener 最终裁框的首帧（512×512）。
- 监督：该条最新 listener caption 原文，`target.text`。
- 输入里没有 listener 的后续音视频。
- `provenance.labels_file` 指回转正标签原行，读取时会核对行 SHA 和 caption 是否被改过。

## 怎么读

在项目根目录执行。`Reader` 只打开通过集；拒绝和未决样本不在这个索引里。

```python
import sys
sys.path[:0] = ["scripts", "src"]
from j_upright_response_sft_data import Reader

root = "experiments/listen_j_upright_response_sft_20261105/final"
reader = Reader(root)
row = reader.row("improvised_V00_S0038_I00000125_local_04af421e3508")
example = reader.load(row["sample_id"])
# example["inputs"]["speaker_audio"]      float32，48 kHz，单声道
# example["inputs"]["listener_first_frame"] 512×512
# example["target_text"]                   caption 原文
```

按 split 取一条：

```python
sid = reader.db.execute(
    "SELECT sid FROM samples WHERE split=? ORDER BY sid LIMIT 1", ("train",)
).fetchone()[0]
```

训练侧把 speaker 音频重采样到 16 kHz，监督 assistant token 加 EOS。封存协议见 `experiments/p2_planning_sft_upright_3b_gpu7_20261105/PROTOCOL.json`。当前 32 卡接续配置是 `experiments/p2_planning_sft_upright_3b_32gpu_resume_20261106/config.json`，数据封存在同目录 `data_seal.json`。
