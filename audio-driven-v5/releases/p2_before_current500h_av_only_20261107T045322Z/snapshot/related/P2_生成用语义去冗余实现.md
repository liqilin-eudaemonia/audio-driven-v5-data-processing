# 生成用语义去冗余：实现与小样本验证

> **当前实现已更新为方案A与Qwen3-30B-A3B-Instruct-2507**：见[原文截取、动作遗漏防护、脚本修复与交接](P2_方案A原文截取去重校验与交接.md)。下文8B自由改写方案及结果是历史试验，不能作为当前实现说明。

2026-10-27，按用户选择的“语言模型整理语义＋代码检查时间和来源”实现。当前范围是独立的生成指导时间线／prompt，原始标签、七类事件缓存和媒体缓存保留。没有更改训练监督头。

## 模型选择

首轮使用本地 `/private/ckpts/Qwen3-VL-8B-Instruct`，只输入文字，vLLM禁用图片和视频输入。选择依据是已有权重与运行环境、现成文本推理路径；不是已验证优于其他模型的结论。没有下载新模型，也没有重新识别媒体。

同一模型分两次请求：先提出整理方案，再检查描述支持、遗漏动作、重复输出、重复发生和冲突披露。第二次检查是模型自检，不等于独立模型验证或人工真值。

## 输出与代码约束

- 模型逐条选择`keep`（作为指令）、`support`（只作为其他保留条目的证据）、`uncertain`或`non_observable`；由代码生成最终清单。每条附原文引用和理由，没有固定行为类别表，也不输出新的数值时间戳。`support`不能再输出第二条重复描述，也不能引用另一个`support`形成循环。
- 代码核对引用ID存在、引用字符串确实属于原文；每条输入必须有明确去向。
- 输出区间完整取自某条已有来源记录，保留其有效区间；不取多个来源的外包区间，不填补静音空隙。引用证据须与所选区间重叠；同一输出的证据必须两两重叠，避免一条宽记录串起分开的重复动作。
- 原音频事件完整复制，不交给语言模型重写。文字、次数、顺序和有效区间保留；同一音频事件的多个静音后有效片段在prompt中只写一次内容。
- 结构校验失败或模型自检拒绝时最多重试三次；最终失败单列，不能伪装为已通过结果。
- 每条派生记录保存完整`source_record`、来源哈希、原文证据、去向、冲突和模型自检结果。

这些约束可以查出不存在的来源、错误引用和时间扩张，但不能用字符串匹配证明新描述在语义上必然正确。局部时间也不一定比整段时间准确；选择局部来源是整理策略，仍需样本复核。

## 运行与读取

在空闲GPU上使用现有环境运行；不停止其他任务：

```bash
CUDA_VISIBLE_DEVICES=<空闲卡号> \
LD_PRELOAD=/private/software/conda/envs/vllm/lib/libstdc++.so.6 \
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=4 \
/private/software/conda/envs/vllm/bin/python scripts/run_listener_semantic_prompt.py \
  --inputs experiments/listen_semantic_prompt_pilot_20261027/inputs.jsonl \
  --output experiments/listen_semantic_prompt_NEW --batch 16 --memory .5
```

`inputs.jsonl`每行包含`job_id`、原整合`record`、带来源角色的`provenance`。当前数据使用`current_postprocessed`，程序要求存在音频后处理标记；历史回归使用`historical_regression_only`。`protocol.json`绑定输入、代码、提示词及模型文件身份；条件变化必须使用新输出目录。

输出包括：`attempts/`原始提案／自检响应，`results/<job_id>.json`通过检查的派生时间线，`prompts/<job_id>.txt`生成指导，`summary.json`成功与失败统计。全部通过才写`COMPLETE.json`。

CPU重放命令：

```bash
python scripts/audit_listener_semantic_prompt.py \
  --inputs experiments/listen_semantic_prompt_pilot_20261027/inputs.jsonl \
  --run experiments/listen_semantic_prompt_pilot_20261027/batch_v2
```

`audit.json`的通过只证明程序约束与重放一致，不能证明语义全部正确。失败记录留在`summary.json`，不能用原始重复prompt兜底后声称“全部去冗余完成”。

这不是原始数据目录的原地更新。以后接入生成，需要以新prompt内容及协议哈希生成新的文本编码缓存；原音视频latent无需因为文字整理而重算。未验证前不替换全量训练配置。
