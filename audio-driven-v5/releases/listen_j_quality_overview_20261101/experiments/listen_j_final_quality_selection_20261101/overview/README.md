# J 最终画质通过数据：完整统计概览（2026-11-01）

本报告仅统计最终画质复筛保留集：**1,107,323段、1,856.25小时**。保留原标注、原划分与全部待核说明；本次没有重新打标、改写描述、合并候选名称或重新筛选数据，也没有生成图表。

## 1. 阅读口径

- **类别数**：现有统计采用的“模态＋开放候选名称”去重数。4,764个名称含近义表达、细分动作及普通动作候选，不能宣称为4,764种互斥或已人工确认的backchannel。另有24个仅待核名称，不计入采用类别数。
- **某类别的数据时长**：包含该类别的完整片段时长，同一片段同类别只计一次；同一片段可以属于多类，因此各类别时长不能相加作为数据集总时长。不是动作本身的精确持续时长。
- **人脸大小**：原视频采样检测框的短边，单位为原始像素，不是预裁框边长，也不是缩放后的512×512画面尺寸。每秒5帧采样，p10/p50仅针对有效检测到的人脸。
- **人脸时长分布**：将片段按其人脸短边p10或p50分组，累计整段时长；不是逐帧达到某尺寸的精确曝光时长。p10是保守值，约90%的有效采样人脸短边不小于它。

## 10. 大脸＋丰富度的训练池容量

仅用于展示可选容量，不实际筛选训练集。下表沿用train划分；“至少3类”只约束采用类别数，不是至少3次动作。

| 人脸p10最低像素 | 不限制类别数：train小时 | 至少3类：train片段数 | 至少3类：train小时 |
| --- | --- | --- | --- |
| 160 | 1,091.32 | 350,620 | 646.00 |
| 224 | 462.63 | 139,481 | 261.94 |
| 256 | 279.95 | 83,898 | 156.83 |
| 320 | 82.84 | 24,740 | 45.95 |
| 384 | 17.18 | 5,103 | 9.39 |

- 仅从时长预算看，300h不能全部采用p10≥256的train片段，因为该池只有279.95h；p10≥224有462.63h，但同时要求每段至少3类后只有261.94h。
- 50h如果同时要求p10≥320和每段至少3类，当前只有45.95h，也需放宽一项或补充其他片段。
- 最终还需叠加类别平衡、来源多样性、每来源数量限制等要求，以上是容量上限，不是已完成的50h／300h训练集。
