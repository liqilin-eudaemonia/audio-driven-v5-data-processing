# HTML 实施清单

设计已获用户确认。设计技能引用的 writing-plans 在本机技能目录和插件目录中未找到；采用此实施清单继续完成已获授权的工作，不为缺少可选工作流插件阻塞实现。

1. 从最终选定版本计算逐阶段通过、时长覆盖、事件数、模型分歧和完整方案指标；给出有证据范围的暂定建议，不把事件数当召回率。
2. 导出 50 条 listener 的 512×512 原帧率静音裁剪预览和独立原始 WAV；校验来源指纹，记录预览与模型采样区别。
3. 构建内嵌数据、无 CDN 的 HTML：分析首页、可排序方案表、共用播放器、2–4 栏事件与覆盖时间轴、人工比较记录、原始回答和资源图表。
4. 复用项目的本地媒体服务模式；输出独立文件、可移植媒体包和预览地址，不改写原始结果或启动模型。
5. 校验统计与原始摘要一致，浏览器验证播放/跳转/筛选/盲评/本地保存/导出/窄屏和媒体 Range 请求；保留截图及检查报告。
