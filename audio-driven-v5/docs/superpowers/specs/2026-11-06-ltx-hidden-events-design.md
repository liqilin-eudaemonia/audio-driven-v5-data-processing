# LTX 主干事件监督

用户已要求先备份，再按讨论方案直接实现。修改前备份：`releases/p2_ltx_hidden_event_before_20261106T030604Z`，1207 文件，压缩包逐文件 SHA256 回读通过。

## 目标与选择

把整段事件监督从 Connector 条件 U 移到 LTX 实际去噪 hidden，并增加历史事件区间的时间监督。保持现有 AV、Feature、Whisper 条件、生成与缓存协议。实现为独立实验模块，原实验及其源码身份不变；不启动正式训练。

考虑过只迁移整段监督、只使用时间监督、两者结合。采用两者结合：当前 19 类整段标签继续提供广覆盖，旧时间标签按实际可用覆盖提供时序目标。六类 GLARE 历史补充仅 15 条，且摇头后被用户否定，不自动作为六类全量真值。现有生产点头与早期模型事件保留弱标签来源、覆盖、未知和时间精度边界。

## 模型

读取最后一个 LTX block 输出、最终生成输出投影之前的视频／音频 hidden。原生 forward 不改动，通过独立显式前向适配器实现相同运算，并用真实小规格 LTX 对照输出和梯度。仅汇聚视频空间维，保留 VAE 时间维；音频保留自身时间维。用目标 token 的真实秒数边界映射事件区间，排除参考帧及补齐尾部。整段和时序分别使用独立多标签头、masked BCE，各自按有效类别／跨卡有效目标数归一化，再加权组合。禁止 detach 生成 hidden。

## 数据

按原始媒体 archive/member（包括 listener 身份）和源视频秒数映射旧片段与 J 片段，不能仅凭 local ID 或文件名连接。历史类别单独保留：点头、摇头、微笑、视觉大笑、皱眉、惊讶、音频回应；视觉大笑不当作音频笑声，转头不当作摇头。原模型时间是弱区间，占用比例可为软目标。未覆盖的类别／时段为 unknown；弱背景必须有明确来源覆盖并单独降权。音频正例须与当前实际静音配方的保留区间相交，不能复活被静音的发声。全部样本仍参与 AV，缺少时间标签不能删样本。

派生 SQLite 和 manifest 冻结目标样本清单、来源文件 SHA、时间原点、类别、政策和覆盖统计；不修改原始标签及缓存。不伪造全量六类 GLARE 覆盖。

## 验证与交付

验证原生 LTX 前向逐值一致、时间边界／空间汇聚／参考帧和尾部 mask、未知与弱负例、并发类别、源身份及重切分偏移、音频 gate、单独 Event 反传到生成 LoRA／Connector／Whisper、冻结基座无梯度、checkpointing、跨进程归一化及保存恢复。运行既有相关回归。提供配置、标签派生命令、检查／训练／推理入口、真实缓存读取与覆盖报告；训练是否启动与验证范围如实记录。
