## 1. 目标和结论边界

用户明确：搜索是为了得到最终生成效果更好的模型，不是为了完成组件消融。

- 只搜索 Event 和 Feature 的监督强度，以实际生成音视频的效果选择权重与检查点。保留已有最好模型作为最终候选，新搜索不保证必然胜出。
- 主要方案从相同初始化分支，通过逐步增加训练预算筛选候选，不要求每组都训练6000步。
- 不声称找到全局最优。短程排名可能变化，早期未改善不能证明某个系数无效。
- 成熟完整模型（如6000步）改变系数后短续训，只能检验该模型的后期调整收益，不能据此确定从头训练的最佳系数；不是本轮主方案。

## 2. 固定pipeline及最终数据

使用完整版本：LTX原生attention／FFN全范围LoRA；speaker Whisper到视频、音频的新增cross-attention全参数训练；AV生成损失＋LTX hidden整段Event＋Qwen hidden经Connector后的双路Feature监督。保持现有rank／alpha、学习率、优化器和AV定义等其他设置，暂不搜索这些超参数。

训练直接复用最终 **train＋dev 284,218段／500.001259小时**、最新caption、当前数值Event标签和已有缓存。沿用原始未做规划SFT的Qwen hidden训练条件，不切换在线Qwen联合微调。不另挑“容易有效”的训练子集；短实验采用相同训练序列前缀。

## 3. GLARE的启发与限制

[本地GLARE论文](../writing/00_GLARE_local.pdf)第9页Table 4(b)尝试0.01、0.05、0.1、0.2、0.5、1.0，提示应检查较宽的辅助监督强度范围。

- 0.05的FVD为142.456、R-F1为0.594；0.1的FVD为144.895、R-F1为0.613。没有一个系数在所有指标都最优。
- Table 4(a)保留Prosody、关闭Reaction时R-F1为0.481；系数0.01时为0.572，因此0.01不等于不加辅助loss。
- 系数1也不自动意味着辅助梯度占主导；影响取决于归一化、共享参数上的梯度大小与方向。
- GLARE逐帧监督与本项目整段Event、屏蔽、弱负例及额外Feature不同，不能直接移植其最优值。

假设是存在有效强度区间，不预判小值无效或大值必然有害。若宽范围结果仍接近，检查梯度路径、评测覆盖和随机波动，不为了拉开分数盲目增大系数。

## 4. 七组宽范围候选

保持现有AV定义及总权重1：

`L = L_AV + lambda_E * L_Event + lambda_F * L_Feature_video + lambda_F * L_Feature_audio`

| 配置 | Event | 视频Feature | 音频Feature |
|---|---:|---:|---:|
| 当前设置 | 0.05 | 0.025 | 0.025 |
| 弱Event | 0.01 | 0.025 | 0.025 |
| 较强Event | 0.20 | 0.025 | 0.025 |
| 强Event | 1.00 | 0.025 | 0.025 |
| 弱Feature | 0.05 | 0.0025 | 0.0025 |
| 较强Feature | 0.05 | 0.10 | 0.10 |
| 强Feature | 0.05 | 0.50 | 0.50 |

Feature数值指每一路各自系数，两路同步调整。两条搜索共用当前设置，共7组，不是16组全交叉。表格不是已部署配置。

## 5. 分阶段训练和筛选

| 阶段 | 建议预算 | 用途 |
|---|---|---|
| 启动检查 | 每组20～50步，计入训练 | 检查梯度路径、loss、更新、显存与稳定性 |
| 第一轮 | 7组各到500步 | 看趋势，仅排除明显失败或退化 |
| 第二轮 | 有希望的约3组到1500步 | 结合多个检查点的真实生成结果首次正式筛选 |
| 第三轮 | 最有希望的约2组到3000步 | 检查优势是否持续、排名是否变化 |
| 最终确认 | 最终候选继续到6000步 | 长程确认，选择模型与检查点 |

3组／2组是预算目标，不是强制淘汰规则。早期尚未学会生成或差异不明确时，延长观察并记录额外预算，不能硬选赢家。

采用同一条完整学习率日程，阶段暂停不能提前压缩学习率衰减周期。晋级时恢复候选自己的模型、优化器、RNG和进度，不从其他候选继承已训练状态。

已有当前系数的记录，仅在初始化、数据／noise安排、优化器和batch等匹配后复用为阶段对照；否则只作已有模型的效果参考。不能默认当前历史31／28batch记录直接满足匹配条件。

少量固定批次可诊断AV／辅助项在共享参数上的梯度、未加权与加权loss、裁剪及数值异常，避免每步增加诊断成本。梯度检查用于确认监督有效，不要求各项梯度等大，也不能代替生成评测。

## 6. 评测数据的角色

用户提出复用最终训练数据和当前统一测评测试集。讨论方案：

1. 训练使用最终500h，不重做一套训练数据。
2. 当前统一测评样本可作为本轮**调参验证集**，复用生成和评分流程；根据其结果选择系数或检查点后，不能再把该集合视为独立测试证据。
3. 另留一批未参与训练、未用于选参的样本，在配置确定后作最终确认；不反复据此挑选配置后仍称其为独立测试。

**原dev已进入500h训练，不能直接作独立验证集。** 执行前核对实际清单以及源视频／对话重叠，不能只比较片段ID或依据test名称判断。独立保留集的清单、数量、来源及本轮重叠审计目前尚未完成。

建议分级测评：

- 粗筛：冻结约64条，覆盖无明显回应、视觉回应、有声回应、音视频共同回应和不同片段时长。
- 正式筛选：扩大到约200条固定样本；候选使用相同规划器版本、推理参数与随机种子。
- 最终候选：增加生成种子复测，配置确定后用独立保留样本确认。增加生成种子不能替代多训练种子验证；若要评估训练随机性，应另行预算训练复测。

## 7. 选择标准

主要判断实际生成的反应和发声是否合适，同时考虑漏回应与无依据地增加回应。画面、身份保持、音质和音画同步不能明显退化。比较多个检查点及类别，避免常见类别改善掩盖其他问题。

不依据加权总loss、辅助头准确率或teacher拟合误差选赢家。小样本FID／FVD仅作辅助。具体主指标、质量退化容许范围及不确定性处理，在查看候选结果前冻结；目前没有已确认的综合分公式或数值阈值。

## 8. 组合及局部细化

粗筛后预留1～2个追加配置：

- 若较强Event、较弱Feature分别有效，测试其组合，不假设单独收益可直接相加。
- 最好值在内部：附近补中间值。
- 最好值在边界：结合稳定性和趋势决定是否向外扩展。
- 差异不稳定：先延长观察或增加验证样本，不盲目新增配置。

新增配置也从相同初始化出发，达到相同阶段预算后比较。

## 9. 成本示例

`7×500 + 3×(1500−500) + 2×(3000−1500) = 9500`个更新步。

若两名候选都继续到6000，再增加6000步，共15500步。相较7组各6000的42000步，示例减少约63%的训练更新量。

该数值不含组合候选、额外复测、生成评分、启动与保存开销；实际步时需实测。匹配的已有记录可减少重复训练，但未核验前不预扣预算。不承诺具体完成时间。
