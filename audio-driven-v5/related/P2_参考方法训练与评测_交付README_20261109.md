## 2. 训练测试交付

### 数据范围

数据来源为[最终 500h 选集](../experiments/listen_j_upright_av500h_train_dev_v3_20261105/README.md)，共 **284,218 段／500.001259 小时**，包括原 train 和 dev，不含 test。读取时绑定最终 listener 裁框、方向恢复结果、配对 speaker 音频及最终自然语言 caption；没有文本输入的原生方法保留原输入形式，caption 记录在数据回执中。

本次实际处理的是选集中的 **3 个训练片段＋1 个分组独立验证片段**，包含 2 秒短片段、11.95 秒最长片段和方向恢复样本。各方法按原生窗口选择可用部分，L2L 因要求 64 帧，排除了两条不足长度的短片段。该划分用于接入诊断，不是独立官方验证集，也不代表已经遍历全量数据。

样本和分组清单见 [DATA_PROTOCOL.json](../experiments/baseline_training_realdata_20261109/DATA_PROTOCOL.json)。

### 关于公开权重

**直接评测公开权重，不需要先重训。** 在自有 500h 数据上训练是另一项实验。本轮 DyStream／Avatar Forcing 的继续训练测试，只验证公开模型能否接收新数据并完成更新。

此前“DyStream 没有公开训练循环”的判断已更正：上游 git 跟踪的 `main.py` 包含训练步骤。Avatar Forcing 本次通过的是基于原生 forward／scheduler 补齐的本地训练入口，不等同于论文完整训练方案。

## 4. 如何查看和复跑

以下命令均从项目根目录执行：

```bash
cd /private/liqi_workspace/project_code/audio-driven-v5
```

查看已有验收，不启动训练：

```bash
python -m json.tool experiments/baseline_training_realdata_20261109/FINAL_AUDIT.json
```

复跑全部七个方法，每阶段默认 4 步，并自动进行新进程恢复：

```bash
/private/liqi_workspace/project_code/Omni-LTX-stage2/.venv/bin/python \
  scripts/p2_baseline_suite.py run
```

只复跑 DyStream 和 Avatar Forcing：

```bash
/private/liqi_workspace/project_code/Omni-LTX-stage2/.venv/bin/python \
  scripts/p2_baseline_suite.py run --methods dystream avatarforcing
```

套件会选择对应隔离环境和固定代码，使用本机物理 GPU7；进程分配上限为 24GiB，启动时要求至少 26GiB 空闲显存。复跑会重写该诊断目录对应的检查点、日志和套件汇总，汇总范围为本次指定的方法。命令用于短跑验收，不会自动启动 500h 正式训练。

复跑七项回归检查：

```bash
PYTHONPATH=src:scripts CUDA_VISIBLE_DEVICES=7 OMP_NUM_THREADS=2 \
  compare/.envs/l2l/bin/python tests/test_baseline_training_realdata.py
```

## 5. 正式训练前的剩余工作

1. 完成全量媒体与各方法原生特征导出，记录失败样本和各方法实际可用时长。
2. 固定分组独立的训练／验证名单。原 dev 已进入 500h 选集，不能直接重复作为独立验证。
3. 补齐 L2L、DIM、DyStream、Avatar Forcing 的全池惰性读取、窗口索引、特征准入及阶段调度。GLARE、ViCo、ListenFormer 已有全池惰性训练入口，但仍依赖完整特征和相应训练统计。
4. 固定初始化、训练步数和公平计算预算，再执行长训练与验证集选模。
5. 如需复现 Avatar Forcing 完整方案，补齐偏好训练阶段；正式推理评测还需检查 GLARE／DyStream 训练中使用的 GT 条件在部署时如何取得。

短片段窗口、检测失败标签屏蔽、原生特征维度、训练条件和确定性恢复的改动均已记录在[技术说明](../experiments/baseline_training_realdata_20261109/README.md)。后续不能仅增加 `--steps`，就将现有诊断入口称为完整 500h 训练作业。

下一步按“恢复原媒体 → 核对时间和人物 → 生成少量样本 → 接官方评分器 → 扩到完整名单”推进。名单的重复区间计分方式也需固定，不能静默删除后仍按 4,107 行报告。
