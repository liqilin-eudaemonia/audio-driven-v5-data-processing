## 模型、时间轴与损失

`src/p2_ltx_events/renderer.py` 显式沿原生 LTX forward 的同一路径读取 `video_out.x/audio_out.x`，位置在输出归一化／投影之前。不使用 detach，不更改原生 forward，也不为 Event 额外完整采样或解码视频。原生 block 的非重入梯度检查点保持启用。

视频 hidden 恢复时间和空间分组，只池化同一时间的空间 token；音频保留自身时间位置。时间坐标直接使用原生 `TextToVideoStrategy` 的 causal position generator。视频 VAE 时间压缩约 8 倍，故监督在潜空间时间网格上；它不是每个原视频帧都拥有独立 hidden。第一帧的因果偏移、固定参考帧、真实片长和音频支持边界均显式处理。

原生 RoPE 坐标会随 latent dtype 使用 BF16；长片段中帧索引甚至可能在除以 fps 前被取整。因此实现分别保留：与原生 dtype／计算顺序相同的坐标用于严格核验，以及 FP32 物理时间边界用于标签。没有用宽松误差掩盖时间偏移，也没有改动原生成器的坐标行为。

视频按原生连续时间／空间顺序 reshape 后做 FP32 空间求和，避免 CUDA atomic scatter 的累加顺序漂移；音频同样保留各自时间位置。

两个独立多标签读出：

1. 生成 hidden 有效时间池化 → 原 19 类整段标签。
2. 生成 hidden 每时间位置 → 8＋1 类时间占用标签。

各分支使用 masked BCE，按跨 rank 有效目标数逐类归一化，再平均有效类别。整段正权重由当前整段统计派生；时间正权重按当前覆盖内的正／弱背景秒数派生并限制到 `[1,10]`。没有足够正负对比的时间类别禁用；整段类别沿用最少 5000 正例约束。没有时间标签的样本仍完整参与 AV 与 Feature 训练。

当前 19 个整段输出中，18 类达到该门槛；`visual:mouth closing` 当前只有 3032 个正例，已屏蔽其损失并保留原始标签和输出位置，没有删样本。

默认总损失：

```
L = L_AV
  + 0.05 * (0.5 * L_hidden_clip + 0.5 * L_hidden_temporal)
  + 0.025 * L_video_feature + 0.025 * L_audio_feature
```

原执行器对梯度做 SUM，损失分母按这一实际约定处理；不能再额外乘 world。日志分别记录 clip、temporal 和组合 Event。Event 梯度可经过 LTX 回到文本注意力 LoRA、Whisper 残差分支／adapter 和 Connector；冻结基座不收梯度。Whisper 的输出残差初始为零，adapter 在残差打开后才获得非零梯度。

Event 读到的是随机 flow 噪声步的去噪 hidden，不是完整采样后最终视频的检测结果。辅助头准确率不能替代生成结果上的独立事件评估。
