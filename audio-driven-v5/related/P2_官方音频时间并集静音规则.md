# P2 官方 listener 音频时间并集静音规则

记录日期：2026-10-26。规则版本：`official-listener-union-gate-v1`。

用户在随机100条复核后确认采用官方 listener **词级、句级、VAD** 三类时间区间的并集。此次授权范围为：记录规则、实现处理、应用到这同一批100条并展示试听结果。不是重新抽样，也不是直接替换全量训练音频。

## 已确认的规则

1. 只使用与 listener 参与者 ID 对应的官方词级、句级和 VAD 起止时间，speaker 时间不参与 listener 保留区间。
2. 整轨时间减片段源起点，转换为片段内时间。先与当前片段相交、裁到合法范围，再对每个有效区间前后各扩展 **0.1 秒**，再次裁到片段范围；最后合并重叠或首尾相接区间。
3. 在这个并集内保留原 listener 波形，其他采样点置零。内部开关边界使用 **10 毫秒平滑淡入淡出**；不另外调响度，不拼接、不变速，不重新分离声源。
4. 三者在当前片段都没有有效区间时，输出等长的全静音 listener 音轨。视频、speaker 音轨和视觉事件保留，片段本身不因此删除。
5. 原音、原始标注和既有缓存保持不变，处理音频写入新版本目录；必须保留配置、来源哈希及保留区间，支持回溯。

片段级“有任一种非空”是发声候选的准入约定；它不表示应保留整段音频。实际波形按时间区间并集处理。片段外近邻标注不能仅凭0.1秒padding被引入原本三者全空的片段。

## 实现约定

- 使用半开采样区间 `[start_sample, end_sample)`，起点向下取整、终点向上取整，以免丢掉标注覆盖的边缘样本。采样率、通道数、样本数保持不变。
- 合并扩展区间后才生成淡入淡出，重叠区域不会反复衰减。
- 淡入淡出采用半余弦（sin²）曲线，放在扩展后的保留区间内；到达物理片段头尾时不额外添加淡变，以保护已经被片段边界截断的回应。
- 10毫秒指从0到1或从1到0的单侧过渡时间，不额外扩展并集。
- 缺失必须的metadata字段、非法非有限时间、负持续时间属于输入错误，停止该样本处理，不回退为“全静音”。零长度区间记录后跳过；合法但完全在片段外的区间也记录并跳过。
- `removed = original − processed`，用于试听可能误删的声音；它不是已经确认的纯噪声。

## 标签与缓存的衔接

**后续更新：** 用户已确认[官方时间对齐与原文保留规则](P2_官方时间对齐与原文保留规则.md)。新版本先对应官方词／单次VAD，无法对应才取交集，原模型时间另存。以下描述是首版静音试听的候选格式，首版结果保留供对照。

此次100条生成独立的处理后候选标注副本，原文和原始时间保留：

- 完全落在实际静音区域的音频事件从处理后有效候选列表移除，仍保存在排除记录中。
- 部分受静音影响的音频事件保留原始描述，额外记录实际保留的时间子区间和覆盖比例；不能继续把整个原区间当作连续发声监督。不会自动把一个词改写成多个词，也不推断新的事件次数。
- 视觉事件逐字段保留。全静音不代表无视觉backchannel。
- 此次不把副本接入训练、不修改现有缓存。如果将来应用到训练，目标音频相关特征缓存必须按新音频哈希重建或失效；涉及音频边界监督时使用上述实际保留区间，不能继续无条件复用旧边界。

## 方法的作用范围

这是基于官方区间的时间门控，不是区间内声源分离。并集内的 speaker 串音和背景声仍可能保留；句级区间内部的停顿也会保留。保留句级范围是当前用户确认的规则，不擅自改成仅词/VAD。

用户已经确认这批复核的规则方向；本轮结果用于核对实际静音边界及保留效果，不声称全量数据不存在官方漏标。
