## 代码与修复

- `code/boundary_core.py`：角色时序、持续接话候选、短回应候选、明确观测支持的空标连接、持续重叠单列、几何稳定性与图像变化共同验证、相邻几何/视觉切点对齐、词末/句末/词间停顿优先的最长11秒分段。
- `code/run_pilot.py`：统一25fps零起点实际解码帧数，逐帧黑屏含EOF、实际音频样本有效终点、完整帧账本、原生裁剪、代码/策略/源文件/标注/新转写哈希缓存验证。未知音频能量为NaN，不伪装成静音。
- `code/transcribe_words.py`：本地 Whisper large-v3，22个有重叠的转写窗口，按词中心归属去重，产生1439个词时间估计；模型时间戳仍可能有误。原ASR粗段尾不再用于本轮句末切点。
- `code/prepare_source.py`：规范化原视频与16kHz原混音。准备步骤显式重新生成，不复用无版本缓存。
- `code/export_review.py`：先精确生成裁剪视频，再单独合入完整原混音，避免同时用视频帧数截止时截短音频。不是listener独立音轨，不作音质筛选或SyncNet准入。
- `code/review.html`：完整新旧时间线、每个pair与未知区间；原画面人物框/裁剪框、同步listener画面、边界前后同位置播放、局部边界时间条、逐帧前后查看、连续播放、浏览器本地审核记录导出。
- `code/test_boundaries.py`：12项边界约束验证，涵盖接话前截断/之后恢复、backchannel保留、缺失观测不填零、有效空标连接、EOF黑屏、音频尾部、几何抖动、稳定变换、切点对齐、完整句子优先、最长11秒与缓存失效。

## 复跑

1. `python code/prepare_source.py`
2. 在有模型环境与授权GPU的节点运行 `code/transcribe_words.py`，`asr_launch.json`记录本次远程进程。
3. `python code/test_boundaries.py`；`python code/run_pilot.py`
4. `python code/export_review.py`，将 `code/review.html` 复制到已配置8798服务的 `full_20261023/reports/boundary_v2_review/index.html`。

路径以当前共享工作区为基准，原数据与模型不复制。旧 `full_20261023` 的生产代码、692份manifest及既有候选均未修改；只在其reports下新增本次审核页。

## 必须区分的限制

自动语义判断仍是试验规则：以0.8秒持续支持、原标注与双方活动分数提出正式接话候选，短暂返回原说话人的片段作为backchannel候选。时长不能单独证明语义，因此所有更改可追溯、可逐帧复核，`training_admitted=false`。本源没有触发额外的“持续重叠”分类，不意味着所有视频都没有重叠。原始角色不明的206.72秒仍需进一步核验，绝不冒充已识别的倾听数据。裁剪框依据局部p0/p1标注，并非跨镜头人物识别真值。

`manifest.json`、`policy.json`、`words.json`、`summary.json`为处理产物；`validation.json`为新旧候选覆盖比较，`browser_validation.json`为页面播放/边界标记/移动端验证。所有源帧可在ledger中追溯。
