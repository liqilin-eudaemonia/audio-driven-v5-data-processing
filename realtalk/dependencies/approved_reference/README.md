最终用户要求：尽量保留完整句子；镜头变化等允许中途截断；尽量多保留数据；目标长度约10秒，最多多1秒，太长必须继续切。

最终规则：最长275帧/11秒，目标250帧/10秒。先恢复同镜头、同角色的连续倾听区间，再对超过11秒的区间做无缝分段。内部边界优先句末，再自然停顿，再词间边界；ASR不可靠时保留帧级兜底能力。必要的镜头、角色、黑屏和不确定区间边界仍保留。短尾段与不完整句子不作为丢弃理由。

plan.py 使用动态规划满足每段≤11秒，优先低成本的句末/停顿候选，同时偏好10秒长度和减少极短尾段；无论切点如何，所有源帧都分配给相邻片段，不删除短尾段。本批选中的三处均为句末候选，没有使用帧级强切兜底。
