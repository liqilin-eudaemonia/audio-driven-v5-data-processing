# RealTalk 全量pair清单与原生人脸/预裁剪框时长统计

统计页：http://127.0.0.1:8798/ 。数据源：/public/0_DATA/2_Avatar/realtalk。

用户确认本阶段仅生成全量切分清单和统计，待确定分辨率阈值后再导出裁剪视频。本目录没有导出全量裁剪视频，也没有应用人脸或预裁剪分辨率过滤。此前V8基线和所有审核批次均未修改。

## 规则

- 对692条视频从0秒到结尾逐帧建立账本；明确说话角色的一方对应另一方listener候选。候选、角色待定、黑屏覆盖全部源帧，无隐藏窗口/条数截断。
- 镜头、布局、角色变化处断开，边界两侧继续提取，不因父片段含问题而整段排除。相邻区间为[start,end)，不自动丢弃切点保护帧。
- 目标10秒，硬上限11秒（275帧）。内部优先句末候选，再声学停顿；无可行边界时按帧兜底并明确标记需要对齐。所有余段保留，没有最低时长/完整句子硬门槛。
- 全量句末候选来自数据集现有ASR文本标点与段时间；这些时间不一定准确，保留boundary_review标记。声学停顿来自同源音频帧级能量，不声称等同可靠VAD或词级强制对齐。全量没有重新跑Whisper大模型，也不隐式复用试验中的人工语义能力。
- 已审核的 -1wCGAxqT_4 沿用最终152条、400.84秒清单，包含3处新切口和两处明确来源的语义复核候选；与该参考逐帧一致。
- 短角色空标最多0.8秒、两侧同角色且不跨镜头、listener无正向说话分数时连接并标记。其他角色空标单独列待定，不判为废片。
- 本阶段未应用音质模型筛选；候选不是已人工验收或训练准入数据。双方同时说话、角色误标、真实listener不可见仍可能需要复核。

## 预裁剪框与尺寸

先按原图中的稳定分屏边界及镜头内人脸框中位数估计固定正方形裁剪，保持原生坐标及像素尺寸。尺度约为人脸较大边的2.35倍，受面板和原图边界约束。无可靠面板或极短镜头时，裁剪框单列unresolved，不丢弃pair。

全量抽检发现上下布局。未验证水平面板边界的上下布局保留pair，但把预裁剪框改列待确认；旧提议框存入proposed_crop_before_layout_review，不混入已知尺寸分布，以免把跨人物的大框误算为高分辨率数据。p0/p1是视频内局部人物标签，常见布局对应左右，上下布局不能照搬左右解释，也不代表跨视频人物身份。

画面采样先按25fps时间轴归一化再取帧；部分AVI的解码帧计数与时间轴存在重复/空帧差异，不能直接使用未归一化的解码n来匹配标注。

两种主要时长分布：
1. **人脸框短边**：逐候选帧统计listener框裁到原图范围后的min(width,height)，按1/25秒加权。缺失、无效、完全落在图外的框单列；越界原框保留计数。
2. **预裁剪框边长**：固定正方形的原生边长，按整条pair时长加权。未确定框单列。没有使用后续放大/缩小到512后的尺寸。

另外保存逐pair人脸宽高/短边的min、P10、中位数、P90及缺框比例；人脸框和裁剪框位置不一致只标记，不筛选。阈值模拟按整条pair保留计算，其中coverage95列额外要求至少95%的帧有有效人脸框。

## 产物

- manifests/<video_id>.json：全部pair、完整时间账本、原视频tar成员与偏移、每段边界来源、原生裁剪框、脸框统计及复核标记。
- reports/pairs.parquet / pairs.csv：全量pair表，含秒/帧区间、speaker/listener、预裁剪x/y/宽高、脸框分位数、缺框比例、位置一致性、原视频定位。
- reports/face_resolution_duration.csv：人脸框短边的时长分布。
- reports/pre_crop_resolution_duration.csv / pre_crop_exact_sizes.csv：预裁剪框尺寸分档与精确尺寸明细。
- reports/pre_crop_size_by_pair_duration.csv：预裁剪分辨率×片段时长的二维分布。
- reports/threshold_retention.csv：阈值→预计保留pair数/小时数，未实际过滤。
- reports/per_video_listener.csv / per_video_listener_resolution_duration.csv：每条视频、每个listener标签的时长加权统计与分辨率分布。
- reports/crop_review.csv：预裁剪框待确认条目；boundary_alignment_review.csv：涉及帧级切口兜底的条目。
- reports/videos.csv：每条原视频的候选/待定/黑屏与有效脸框时长。
- reports/summary.json、PNG/SVG图、manifests.tar.gz、provenance.json：汇总、独立图表、完整清单包与来源指纹。

## 核验与复跑

运行：`OPENBLAS_NUM_THREADS=1 python code/run_all.py`。有清单的视频自动跳过；独立geometry审核版本也可增量恢复。扫描和面板缓存位于scans/，仅为本工作目录的分析缓存。

每条视频检查：源帧账本连续、无重叠；原始明确角色的非黑屏帧全部纳入候选；每段≤11秒。汇总检查：脸框直方图帧数守恒，预裁剪已知＋未知时长守恒，CSV/Parquet与清单条数一致，阈值曲线单调，原审核示例152条区间不变。独立抽样重新从原始标注计算人脸尺寸；可视化抽样截图见native_crop_contact.jpg，其中早期截图包含后来被标为上下布局待确认的提议框。

数据清单仍保留所有不确定性，统计结果不能直接解读为最终训练可用小时数。源视频位于原tar中，使用只读subfile偏移访问，未重复展开249GB原片，也未改变原数据。
