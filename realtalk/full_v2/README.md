# RealTalk 全量 v2（2026-10-25）

用户确认的边界算法全量应用。原始数据：`/public/0_DATA/2_Avatar/realtalk`，692条。原始索引只用于定位源视频、人物框与活动评分，不复用旧pair边界。

流程：原始视频归一化时间轴 → Whisper词级时间戳 → 用户确认的v2边界 → listener本人视觉绑定的AV_MossFormer2_TSE_16K分离 → 自适应音量优化 → listener画面分别匹配优化前后音轨的SyncNet。短回应保留；正式接话前切断，交换角色继续；镜头/布局/黑屏处切断；句子尽量完整、上限275帧/11秒。短片段的分离上下文不得越过同一角色连续区间。

- `manifests/`：新pair和所有源帧的分类记录，含原生裁剪框、连续角色区间、边界原因。
- `videos/<id>/`：归一化源视频/音频、ASR窗口、词时间戳、分镜扫描和切分清单。
- `audio/<id>/`：listener分离原始WAV、进一步优化WAV、用于评分的脸部画面。`*_face.avi`是模型输入，不是最终原生裁剪视频。
- `results/<id>/`：每段人物、原生裁剪框、分离模型SHA、输入清单SHA、音轨SHA、优化参数和两组SyncNet结果。
- `reports/`：全量进度、优化前后通过清单；短片段/静音/身份待复核/技术异常单列。
- `state/`、`video_status/`、`logs/`：源视频阶段和日志；每条源视频最多三次自动尝试。
- `validation.json`：已确认137条pair逐字段一致；核心算法字节一致；分离/脸部编码/SyncNet核心函数AST一致；短上下文不跨角色边界。
- `code/`：全量入口与依赖；`code_snapshots/`：启动时精确快照。

未应用分辨率阈值；全量输出切分、音轨和评分，原生裁剪视频先抽样，沿用确认阈值后再全量导出裁剪视频的约定。SyncNet通过仅表示该模型下的口型匹配，不能证明没有串音或角色语义完全正确；短片段、静音及不可评分记录不当作普通筛选失败，候选不自动标记训练准入。

运行环境为 `../av_baseline_pairs_20261024/venv/bin/python`（包含分离模型依赖）。在node8上运行`code/supervisor.py`，根据空闲显存安排每卡1–2个常驻worker，使用8张卡，不停止其他任务。每条源视频加文件锁；模型常驻；断点按代码、输入清单、模型、音轨哈希检查。后台任务不依赖聊天或浏览器存活。
