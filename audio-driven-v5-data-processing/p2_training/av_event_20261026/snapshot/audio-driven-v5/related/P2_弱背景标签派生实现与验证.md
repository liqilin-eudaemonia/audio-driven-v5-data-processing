## 1. 已实现的监督约定

正常完成标注且媒体有效的 listener 区间中，接受的事件为 1，其余时间为弱背景 0；unknown、失败、未处理、截断边界及 padding 屏蔽。跨 bin 边界使用事件占用比例。保留共享 U 上现有的七类 MLP、masked BCE-with-logits、类别 `pos_weight`、有效 bin 归一化和 `λ_event=0.05`；首轮没有独立背景降权，也不增加动作强度标签。

实现入口：

| 文件 | 职责 |
|---|---|
| [weak_labels.py](../src/p2_listen/weak_labels.py) | 验证完成回执、listener 媒体来源，派生 coverage、事件接受记录、unknown 与审计结果 |
| [p2_listen.py](../scripts/p2_listen.py) | 新增 `derive-weak-labels`；后续沿用 `import-labels`、`cache --part events` |
| [新配置](../configs/p2_listen_weak_background_v1.json) | `mapping_version=listen-candidate-training-v2`、`admission_policy=event-interval-weak-background-v1`，使用独立输出目录 |
| [新增回归测试](../tests/test_p2_listen_weak_labels.py) | 19 项弱背景派生/回执/梯度测试；与原 72 项 P2 测试一起执行 |

`candidates.py` 原入口仍要求显式 decisions，不会因为升级代码就把旧候选自动变为负例。模型、损失、DDP 归一化和正式训练准入保护均沿用已有实现。

## 2. 成功覆盖的判定及保守处理

v1 针对已有完整视图回执格式接入，不要求人工逐段填写背景。每个模态要求恰好一条 `view=full`、`status=schema_pass`、正常结束且含有效 parsed events 列表的回执，时间必须覆盖完整真实片段。多条成功完整回执存在歧义时直接报错；只有失败记录、缺少完整视图或仅有滑窗时，该模态不产生背景监督。整份必需文件缺失则命令报错。

- **视觉：** 回执的来源视频、裁剪变换、时间原点必须匹配媒体导出清单；帧必须是 512×512、时间有序且覆盖完整窗口。v1 对首尾和相邻采样空隙采用不超过 0.25 秒的完整性检查。这证明媒体采样条件合格，不证明模型没有漏标。
- **音频：** 必须是独立 listener 音轨，音频回执哈希须匹配训练目标 WAV，并核对源音频哈希、采样区间与采样率。speaker 音频、混合音频、哈希不符都不能用于生成 listener 背景标签。
- **有效媒体：** `prepare` 已检查实际视频解码、尺寸、帧率、音轨时长和媒体哈希。派生再次绑定 prepared targets 与媒体导出哈希；不能只看 HTTP 成功状态。
- **事件：** 直接保留已有语义类别、原文和时间，不再用关键词分类，不裁短非法事件。仅弱接受 `raw_model_unverified`、`normalization_unverified`、`inherited_interval_union_requires_boundary_review` 这三类来源/边界待核验标记；其他 flags 保守 unresolved 并屏蔽相关区间。`reviewed_flags` 在此表示策略显式处理，不能解释为人工审核。
- **真实不确定：** 保留上游局部/逐类 unknown；未解决事件、定位失败或音频内容冲突继续屏蔽。显式 censored、词对齐 `timing_evidence.edge=true`、跨越片段边缘的事件保守屏蔽，其原始事件仍保留供追溯。
- **历史占位：** 只有明确传入 `--replace-unadmitted-placeholder`，且源 schema/version 精确匹配已知 v3 格式、全七类整段 unknown、coverage 全空、`K_train=[]`、未准入时，才替换这个“尚未准入”占位。保存原 unknown 与替换标志；其他版本及局部 unknown 不清空。

成功且没有事件的样本可产生弱背景；音频失败不影响成功的视觉覆盖，反之亦然。接受的事件可能因 unknown/censored 不参与损失，因此“接受事件数”不等于“有效正例数”。

## 3. 输入、命令与产物

先用新配置执行 `prepare`，将输入/目标清单写到其独立 `output`。`--observations` 在下面的派生命令中特指**开放事件观测文件**，不是 `prepare` 的 speaker 音频/首帧输入清单。

```bash
cd /private/liqi_workspace/project_code/audio-driven-v5
P2_PY=/private/liqi_workspace/project_code/Omni-LTX-stage2/.venv/bin/python
P2_CFG=/path/to/new_experiment_config.json
P2_SOURCE=/path/to/annotation_bundle
P2_DERIVED=/path/to/new_empty_derived_directory

"$P2_PY" scripts/p2_listen.py prepare --config "$P2_CFG" \
  --observations "$P2_SOURCE/observations.json" --targets "$P2_SOURCE/targets.json"

"$P2_PY" scripts/p2_listen.py derive-weak-labels --config "$P2_CFG" \
  --candidates "$P2_SOURCE/integrated/labels.candidate.jsonl" \
  --review "$P2_SOURCE/integrated/review.json" \
  --observations "$P2_SOURCE/integrated/observations.jsonl" \
  --visual-results "$P2_SOURCE/raw/visual.jsonl" \
  --audio-results "$P2_SOURCE/raw/audio.jsonl" \
  --media-manifest "$P2_SOURCE/media_manifest.json" \
  --source-summary "$P2_SOURCE/summary.json" \
  --replace-unadmitted-placeholder --output "$P2_DERIVED"

"$P2_PY" scripts/p2_listen.py import-labels --config "$P2_CFG" \
  --labels "$P2_DERIVED/labels.admitted.json"
"$P2_PY" scripts/p2_listen.py cache --config "$P2_CFG" --part events --device cpu
```

最后一条命令要求 input 缓存已经存在且身份一致。只改变标签时不需要重提取 Omni H；新实验可核对身份后复用 input，事件缓存必须独立重建。首次数据接入尚无 input 缓存时，先按[运行说明](P2_倾听事件监督实现与运行.md)缓存 input。不要拿不匹配的缓存改名代替。

派生输入的 sample IDs、时长、review 与 candidate 事件内容必须一致；当前命令只接收 train 样本，拒绝将自动弱标签当作 dev/test 人工参考。`source-summary` 必须明确提供布尔 `debug_only` 与 `formal_training_admitted`；任一来源仍属 debug 或未获正式准入时，新结果保留调试限制，不能通过宽泛 summary 擦掉单条记录的 debug 身份。正式数据的媒体/用途准入与弱标签接受是两个不同步骤。

输出包含 `labels.json`、可导入的 `labels.admitted.json`、逐事件 `decisions.json`、排除/覆盖审计 `audit.json`、每类背景秒数/unknown 统计 `summary.json` 和字节不变的 `sources/`。标签保存原始事件、来源文件 SHA256、目标音视频哈希、覆盖假设、策略版本和 `human_verified=false`。输出目录须为空，原始文件不覆盖。

输入格式实例可直接查看本次[原始调试数据目录](../experiments/listen_debug50_fullraw_20261025/)；其 targets 文件名为 `targets.debug.json`，不是上面正式接入占位示例的 `targets.json`。该数据包含调试选择范围，不能据此扩张正式主池范围。
