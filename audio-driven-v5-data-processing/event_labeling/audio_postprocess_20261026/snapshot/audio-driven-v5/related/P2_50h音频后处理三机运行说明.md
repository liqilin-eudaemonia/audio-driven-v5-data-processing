# 50h 音频后处理：代码与三机运行说明

2026-10-26。已使用 node17、node12、node4 的24张GPU完成固定50小时训练子集的音频后处理，30,415段全部通过验收。新数据与音频缓存已就绪，未启动训练。

## 规则与范围

固定使用 `experiments/p2_train50h_backchannel_face_20261026/sample_ids.txt` 的30,415段，50小时零4.006秒，全部train。完整保留片段及speaker输入、人脸裁剪、六类视觉标签、原视频缓存；不重新筛选，不混入dev/test。

1. 官方listener词、句、VAD区间并集，片段内裁剪后向两侧各保护0.1秒，内部边缘10毫秒淡变。并集以外静音，空并集保留等长静音。
2. 音频事件沿用已验证的原文与时间对齐算法：近邻唯一同词匹配可采用官方边界，其余使用原事件与有效区间的交集；不使用官方转写改写模型原文，不新增事件。
3. ASR原文含两个及以上汉字时，删除该事件并静音对应有效区间；单个汉字继续保留。不扩大到所有非英语内容，不把删除规则声称为噪声检测真值。
4. 输出JSON配方，读取原WAV后在内存中处理；不额外生成整套WAV。仅更新音频latent与事件缓存，原缓存不覆盖。保留原始事件及排除审计。

缺少官方metadata文件或必要字段会报错；不会当作空VAD并静音。官方时间转为当前片段相对时间，再执行上述规则。

## 并发与续跑

CPU阶段24个归档读取线程、32个配方准备线程，避免逐样本反复扫描同一tar。官方记录整理完成后，先冻结完整样本范围和记录SHA256，再让配方准备与GPU编码同时运行；worker逐样本等待原子写入的配方和标签，不等待整批准备。最后仍需完整index及全量验收通过才算完成。音频阶段固定96个互不重叠分片，三机各32个worker，每张GPU4个常驻原生编码器，每个worker使用2个CPU线程；不降低精度、不改变裁剪或事件语义。音频VAE较小，显存不需要填满，性能以实际段/秒和GPU/CPU负载判断。

完成标记和逐样本文件锁支持重跑跳过，失败worker最多自动重试一次；错误有独立日志，禁止静默漏样本。控制进程与节点均有锁。GPU资源每5秒记录、汇总约每15秒更新。没有恢复已被用户停止的20分钟定时聊天汇报。

## 训练端如何读取（用户确认：不存新WAV，保留latent缓存）

**后续训练使用新入口：**

```text
/private/liqi_workspace/project_code/audio-driven-v5/experiments/p2_train50h_audio_postprocess_20261026/view/config.json
```

配置中的 `data.audio_postprocess` 已绑定原缓存目录与本轮处理策略SHA256。不能继续使用旧E1配置期待自动获得新音频；也不能直接把 `manifests/targets.json` 中的原WAV作为处理后的波形。

训练的数据路径已经接入：

```text
p2_listen.training.train
    → p2_listen.training_data.load_training_sample
    → listen_audio_postprocess.overlay.load_training_sample
        输入：原speaker音频特征、参考图特征、原文本特征
        视频目标：原视频latent
        音频目标：本轮处理后的音频latent（原波形没变化时明确复用原缓存）
        事件目标：本轮过滤后的七类事件缓存
```

训练开始前的逐条加载检查和每步正式训练循环都调用上述入口。音频更新按原几何信息组合，保留音频支持mask、真实时长和尾部token处理；缓存缺失、哈希或身份不一致时会报错，不会回退到未处理音频。该路径不需要在每次训练时重新执行音频VAE。

物理保存的内容是：原媒体引用、逐条静音配方、处理版本与来源哈希、过滤标签及审计、新音频latent和事件缓存。**没有物理保存新的处理后WAV，没有复制视频latent。** 原有试听样本的WAV属于先前复核产物，本次50h不再批量生成。

如果后续评估或试听需要波形，应按配方在内存中读取：

```python
from pathlib import Path
from p2_listen.contracts import read
from listen_audio_postprocess.recipes import read_listener_audio

view = Path("experiments/p2_train50h_audio_postprocess_20261026/view")

waveform, sample_rate, audit = read_listener_audio(recipe)
# waveform是float32 [采样点, 声道]，已按确认规则处理；函数不写WAV。
```

训练读取实现：[training_data.py](../src/p2_listen/training_data.py)、[overlay.py](../src/listen_audio_postprocess/overlay.py)。本轮额外完成固定100条GPU对照：100条虚拟波形与已试听WAV逐采样点一致，98条新编码缓存与同GPU编码实体WAV逐位一致；2条原波形未变，复用原缓存。详见 [GPU验收记录](../experiments/p2_train50h_audio_postprocess_20261026/gpu100_acceptance.json)。没有启动训练。
