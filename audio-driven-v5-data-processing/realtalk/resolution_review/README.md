本地审核：http://127.0.0.1:8798/resolution_review/ 。11 个有数据的原生预裁剪尺寸档，各3条，共33条；每条最多展示6秒，同屏展示原画、绿色预裁剪框、放大到512px的结果，同时提供不缩放的原生裁剪视频。音轨保持源混合音频。
